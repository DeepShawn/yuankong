# Windows 本机网站限制

在电脑上右键以管理员身份运行 Windows 包内的 `WebsiteRules.cmd`。本工具仅在本机控制台运行，每次修改前显示新增、移除的域名并要求输入 `APPLY` 确认；不自动提权，不通过远控接口写系统文件。

选择 `1`，逐行填写完整域名，空行结束。新列表会替换**本工具当前的列表**。选择 `2` 可以撤销本工具的全部规则。

例如，限制 `example.com` 和 `www.example.com`，需分别输入这两个域名。它不支持通配符、网址路径、端口、IP 或应用进程规则。国际化域名会转换为标准 ASCII 域名。已有其他 hosts 映射的域名会提示冲突，不覆盖原映射。

规则使用 Windows 系统 hosts 文件中的明确标记区，写入每个域名的 IPv4、IPv6 阻断条目。其他条目、注释、原有编码字节及换行保留。每次有实际改动时，修改前副本保存在 `%LOCALAPPDATA%\LocalWebsiteRules\backups`，不会自动删除；恢复操作只移除本工具标记区，保留其他程序之后新增的内容。标记区损坏、含手动添加的非工具内容、文件链接异常或检测到并发修改时拒绝写入。

写入先完成备份和同目录临时文件，再核对原文件修订并调用 Windows `ReplaceFileW`，保留原文件 DACL。系统或安全软件拒绝替换时不会清除只读属性、更改权限或改用原地覆盖。替换后核对实际文件内容，并尝试刷新 Windows DNS 缓存。与其他程序同时编辑 hosts 仍可能产生竞争，使用时请关闭其他 hosts 编辑器。

这些规则不需要进程、服务或计划任务：确认写入后，接收端退出或电脑重启也会保留。因此无需将本工具加入 `start.bat`，也没有新增启动通知。

**能力范围：**仅影响这台 Windows 电脑采用系统域名解析的请求；不等同于防火墙。浏览器的加密 DNS、VPN、代理、直接 IP、应用自己的解析缓存及已经建立的连接可能绕过或延后限制，不保证所有程序即时无法联网。必要时关闭并重新打开有关应用。

hosts 不提供访问时间、网页记录或手机应用识别，也不会管理热点下其他设备。本工具不记录网络活动，不新增任何监听端口、远程改写入口或后台监控功能。Android 远程网站管理和热点访问记录不包含在此本机工具中。

# LanCmd 2.9.0

优化占位文件生成速度，并修复 USB 常规停用接口被驱动以 0x17 拒绝时的兼容与恢复流程。

- 占位文件优先快速预分配真实磁盘空间，最大16GiB分段处理以支持取消；设置普通文件长度并核实实际分配，仍支持0–500GB、隐藏+系统属性、至少1GB剩余空间。
- 不使用稀疏文件或 SetFileValidData；文件读取零值由 Windows 的正常有效数据保护提供。明确不支持快速分配时，清理未完成预留并重新逐块写入；权限、磁盘满等错误直接报告。
- 分配期间可取消；当前系统调用返回后清理。速度取决于文件系统和磁盘，不保证500GB瞬间生成。
- USB 0x17 等常规接口否决时，尝试所选 USB 磁盘的 SetupAPI 兼容变更，核验 DiskDrive 类与 USB 归属。保护系统磁盘，不操作父控制器、集线器或其他设备。
- 兼容变更前保存配置恢复标记。即使设备仍启用，也能撤销尚未生效的停用设置；需要重启时保留恢复记录、不自动重启，只有读回已停用才报告断开。
- 继续包含2.8.0文件索引搜索、分组菜单、最后修改日期选择及摄像头恢复功能。

请同时安装新版 APK、更新完整 Windows 包；先停止旧接收端再替换和重启。2.6.0的旧进程不能通过只更新安卓修复。接收端不新增应用弹窗，系统安全与隐私提示保留。

自动检查覆盖小文件的实际集群分配与零读取、回退写入、取消与崩溃清理，以及 USB 备用接口和待生效配置恢复。500GB边界仅使用模拟验证，不在 CI 中真实占用500GB；ASolid USB等实体驱动仍需目标电脑确认。

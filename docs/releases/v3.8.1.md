# LanCmd 3.8.1

修复热点已开启并有客户端连接，却提示无法确认热点专用网卡的问题。

- 除传统 ICS 共享标记外，增加当前客户端 MAC、IPv4 网段与活动 Wi-Fi Direct 虚拟网卡的交叉识别；不固定依赖某个名称或默认热点 IP。
- 安卓新增「选择热点网卡」和「恢复自动识别」，Windows 保存选择。候选不明确时可选择实际共享网卡；所选网卡消失时停止旧规则，保留客户端限制列表，避免作用于其他网卡。
- 热点已开启时不再要求先开启，识别依据及诊断详情可查看；同一错误不重复展示。

请同时更新安卓与完整 Windows 包并重启接收端。进入「网络与蓝牙 → 热点」刷新，仍有多个候选时使用「选择热点网卡」，然后重试指定客户端的禁止联网。

保留 ZIP 直接上传、升级成功后旧包清理、设备级启停、原生触控与 miuix 主题。双端 **3.8.1**，安卓 versionCode **52**，沿用原签名。Windows 不新增应用弹窗，必需的系统权限及安全验证保留。原生 API 与识别回归通过不等同于已在用户具体无线硬件上实测。

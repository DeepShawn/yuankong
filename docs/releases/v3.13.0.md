# LanCmd 3.13.0

- 占位文件分批刷新，减少分配结束后集中等待，跳过重复的末尾刷新；收尾恢复普通 I/O 优先级，单独显示关闭状态，真正关闭后再报告完成。磁盘系统调用仍须等待设备返回，不承诺特定 U 盘耗时。
- 文件管理 → 编辑与属性 → 更改实际大小：0–500 GB，整数字节，后台任务可查看／取消，沿用文件延迟。扩展末尾补零；缩小永久删除尾部数据，须先确认与备份，不是压缩文件。拒绝受保护路径、链接、多硬链接、过期选择及正在写入的文件，保留来源数据流。取消扩展尝试恢复原大小；接收端异常退出可能留下部分扩展，缩小无法撤销。
- 文件来源按可编辑说明实现：填写原网址或备注，最多 2000 字，保存在 NTFS 等支持命名数据流的卷中；独立版本校验并支持延迟保存。不修改 Windows 安全来源标记，不充当真实性证明；不支持数据流的磁盘、手机传输及部分复制方式不保留此备注。
- 新增滚动公告：跑马灯、全局弹窗、桌面常驻，支持自定义文字、前缀、字体、粗体、颜色、形状、位置、宽度、透明度、速度、次数及显示时长。
- 提供左右／上下滚动、往返、静止与淡入淡出，手机本地动态示意预览，保存草稿；支持 Windows 暂停、继续、撤回，电脑 × 或 Esc 关闭。手机断线继续，接收端退出结束。
- 经典预设参考[希沃官方公开消息通知示例](https://help.seewo.com/hugo/seUwokPXWT)，自绘图标，不依赖第三方组件；未取得特定版本的精确动画参数，不宣称逐像素一致。
- 全局命令延迟和全局操作延迟分别设置 0–86400 秒，Windows 计时，支持待执行列表和取消。单项明确延迟覆盖全局，不重复叠加。
- 实时控制、查询、传输分块、认证、恢复、停止／取消及升级保持即时。上传、下载、手机 WPS 等待仍需手机在线。接收端退出会取消待执行任务，不重启重放；网络权限和文件身份在真正执行时继续校验。

更新安卓和完整 Windows 包后重启。沿用原 APK 签名、miuix／KernelSU 风格和本地 ZIP 升级。

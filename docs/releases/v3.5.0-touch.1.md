# LanCmd 3.5.0 原生触控版

新标签 **v3.5.0-touch.1**。原 v3.5.0 的标签和安装包保留。

- 手机远程画面发送触点帧，使用微软官方 `InitializeTouchInjection` / `InjectTouchInput`，包括单指、多点、移动、抬起、取消；保留手机触控圆点。
- 默认触控不再调用鼠标移动，也不替换／恢复系统鼠标图案。共享结束只释放触点；鼠标兼容按钮移到「更多操作」，使用时明确采用鼠标输入。
- 独立工作进程在断线、会话结束、父进程退出或心跳超时后释放触点。校验坐标、完整触点帧与生命周期，避免断线留下按住的触点；多连接和手势回放互斥。
- 这是微软官方软件触控注入接口，**不是安装虚拟 HID 内核驱动**。接口不可用时明确报错，不自动回退为鼠标。
- Windows 按自身规则管理触摸／鼠标显示。实际鼠标再次被使用时可以显示指针；部分应用可能自行绘制图形，不能承诺全局永久隐藏鼠标。

显示版本按要求为 **3.5.0**。安卓 `versionCode 48`，Windows 内部升级序号 **3.5.4**，使现有 3.5.3 能正常升级而无需放松防降级校验。文件名带 `touch.1`，避免和原 3.5.0 混淆。

**需要同时更新完整 Windows 包并退出旧进程重新启动，以及覆盖安装新版安卓。** 保留现有签名、miuix 主题、文件搜索与本地 ZIP 升级流程，不增加在线更新。

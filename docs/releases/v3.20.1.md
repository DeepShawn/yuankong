# LanCmd 3.20.1

安卓首页“电脑”入口改为 **“切换电脑”**。进入后用现有局域网发现协议刷新接收端列表，保留 Liquid Glass 界面、备注、搜索和连接历史。

- 多台接收端同时在线时，每台显示名称、地址和发现状态。当前连接标为“当前电脑”；点击另一台的“切换”按钮才会更换目标。搜索、刷新、备注和查看历史不会自动切换。
- 切换先关闭旧的主连接，等待旧连接循环退出后再连接目标；重复点击当前电脑不会重新连接，快速连续选择以最后一次为准。返回首页或重新打开列表不会因为退出页面而断开新连接。
- 手动选中的目标会保存在手机。离线后只重试该目标；重新发现时按接收端标识及端口匹配，不再因为目标暂时没响应而选择其他接收端或热点网关。已有标识与握手返回不一致时拒绝连接。
- 每台电脑沿用独立的配对凭据。旧功能页的请求保留原连接约束，切换后需重新打开有关页面；不会把旧页面请求转交给新电脑。旧电脑已确认的后台任务不会迁移到新电脑，也不会因手机切换而自动取消。
- “更多 → 手动输入电脑地址”使用相同切换流程，修复已连接时仅改变保存地址却没有实际切换的问题。

“本次发现”表示接收端响应了此次发现请求，不等同于持续在线监测；没有响应也不代表电脑关机。标识检查用于防止误连，不代替加密的身份验证。没有新增扫描范围、批量控制、授权绕过或 Windows 消息提示。

本次改动在安卓连接管理及界面。Android versionCode 74、版本 3.20.1，保留原签名和应用内更新。Windows 仅显示版本同步为 3.20.1，功能、协议与升级序列（3.18.8）不变；**使用此功能只需更新安卓 APK**。

发布文件：`LanCmd-3.20.1.apk`、`LanCmd-Windows-3.20.1.zip`、`SHA256SUMS-3.20.1.txt`。

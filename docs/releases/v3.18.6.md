# LanCmd 3.18.6

## 轮巡速度

在“滚动公告 → 播放与延迟”中，希沃样式可设置 **25–300%** 的轮巡速度，或选择 0.5×、原速、1.5×、2×。100% 与原版本的速度和外观一致，2× 的完整一轮时间是原速的一半。

只改变播放节奏，保留尺寸、颜色、图标、固定蓝色前缀和白色正文轨道。手机预览与 Windows 使用相同倍率，修改速度后手机预览从头开始。经典样式仍使用原有的像素／秒速度控件。

## 循环后自动撤回

选择“循环 N 次”并填写 1–100。单条播完算一轮，多条全部播完算一轮；达到 N 轮后由 Windows 自动撤下公告，确认窗口已销毁后，安卓显示 **“循环完成，已自动撤回”**。

- 手机断线不会取消电脑已确认的播放和自动撤回，电脑及接收端须保持运行。
- 暂停不计播放时长；选择“一直循环”则需要手动撤回。
- 选择按时长结束时，到时同样自动撤回。
- 自动撤回只撤下电脑上的公告，保留手机草稿与速度设置；重新打开页面不会自动发送。

自定义倍率和撤回确认需要完整更新 Windows 包并重启。旧接收端仅允许默认倍率，未提供撤回确认时安卓保持“播放完成”提示。

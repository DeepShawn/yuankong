# LanCmd 3.19.0

安卓界面按 **Liquid Glass（液体玻璃）** 标准重构，滑动与切换改为跟手回弹。Windows 接收端功能未改。

- 视觉：半透明玻璃卡片、1 dp 渐变高光描边、柔和阴影和大圆角；顶栏改成悬浮玻璃胶囊，底部工具 Dock、输入框、开关、按钮、进度条和对话框统一为同一套玻璃材质。背景是缓慢流动的极光光斑，深色优先，同时保留亮色/跟随系统背景与 12 种主题色 × 6 种背景色调。
- 动效：页面进入时缩放上浮、退出时轻微推远；首页分类切换轻推回弹，底部 Dock 的液体指示器用弹簧跟随；按钮按下回弹。所有装饰动画遵循系统「关闭动画」设置，不新增无限动画、不做全屏实时模糊。
- 性能：极光背景只绘制一次静态画布，动画仅改变图层位移和缩放，不重绘画布、不重组页面；玻璃层数受控，列表页使用静态柔焦背景 + 薄玻璃，避免每帧模糊。中低端机掉帧时优先减少装饰动画，功能与点击不受影响。
- 外观设置保留：主题色、背景色调和「KernelSU 参考风格 / miuix 经典风格」选项都还在；两种风格现在都使用 Liquid Glass 材质，只调整间距与密度。设备与网站规则等既有功能入口、文案和连接行为未变。
- 只改安卓端：Windows 接收端的功能、协议、文案和升级序列保持不变；Windows 包的显示版本同步为 3.19.0，构建版本仍为 3.18.8，需完整更新以保持版本一致。
- 双端版本 3.19.0，Android versionCode 71，沿用原签名。单元/集成测试全绿。

已知限制：玻璃效果不采集屏幕内容做实时模糊，只模拟折射与高光；系统开启「移除动画」时页面与 Dock 保持静态。极光背景在低端机上为静态渐变，不影响滑动。

发布文件：`LanCmd-3.19.0.apk`、`LanCmd-Windows-3.19.0.zip`、`SHA256SUMS-3.19.0.txt`。

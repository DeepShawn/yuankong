# LanCmd 3.20.2

在安卓首页打开「外观主题」，可以预览 miuix 和 Liquid Glass，再点「应用」。使用新版界面只需更新安卓 APK。

- **miuix** 使用实色卡片、分组列表和明确的选中状态。
- **Liquid Glass** 使用半透明卡片、流动极光背景、网格工具入口和悬浮底栏。
- **命令控制台** 在空间充足时把输入区固定在底部，输出区占满剩余空间。切换主题会保留命令草稿。
- **工具库和列表** 支持全屏搜索工具。电脑切换和文件管理压缩了顶部操作区，文件搜索展开筛选后仍可滚动结果。
- **窄屏与大字体** 操作按钮可按宽度换行，顶栏按实际文字高度布局，长状态提示可展开查看。

可在安卓端「更多 → 检查更新」获取新版，也可下载 `LanCmd-3.20.2.apk` 覆盖安装。Android versionCode 为 75，安装包沿用正式版签名。此次同步提供 Windows 安装包，接收端的构建序列为 3.18.8。

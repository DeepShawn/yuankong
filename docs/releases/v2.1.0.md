LanCmd 2.1.0 新增安卓外观主题，并改进布局。功能、通信协议和操作流程与 2.0.0 相同。建议同时更新安卓与 Windows 完整包，保持版本一致。

- 外观主题：首页右上角调色板按钮或「更多 → 外观主题」打开。可选 6 种主题色（薄荷、海蓝、紫罗兰、琥珀、玫瑰、青柠）和 4 种背景色调（深海、午夜蓝、石墨、纯黑）。所有页面、对话框和虚拟键盘同步换色；错误、警告、成功的状态色保持不变。设置保存在手机上。
- 切换主题后首页会重新加载，控制台日志、历史命令和 CMD/PowerShell 选择都会保留。
- 首页：电脑音量、常用命令、U盘锁 / 设备、延迟命令列表改为带图标的 2×2 排列，按钮更宽，文字不拥挤；快捷入口更紧凑，控制台区域更高。
- 功能页：并排按钮之间自动留出间距，卡片内边距和卡片间距加大。

Windows 接收端仅更新版本号至 2.1.0，接口与行为与 2.0.0 相同。升级前停止旧 Windows 接收端，替换完整目录；请保留原配置及 `device-policy.json`。安卓继续沿用发布签名，可覆盖安装 1.4.10 及之后版本。

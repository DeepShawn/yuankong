# LanCmd 3.20.0

安卓新增**应用内自动更新**，并按真机观感重做 Liquid Glass 视觉；Windows 接收端功能未改。

## 应用内自动更新（安卓）

- 应用启动时每天最多检查一次 GitHub Release，也可在「更多 → 检查更新」或「关于 → 检查更新」手动检查；检查失败只提示原因，不影响连接和其他功能。
- 有新版本时首页显示玻璃更新卡片：可以查看更新说明、显示安装包大小、下载并显示进度、取消下载。下载完成后校验包名、版本和官方签名证书，通过后才交给系统安装；签名不一致会拒绝安装并删除临时文件。
- 未授予「安装未知应用」权限时自动跳转授权页，返回后继续安装。Android 系统仍会显示安装确认，不做静默安装或后台替换。
- 更新只访问公开的 GitHub Releases API，不引入任何第三方更新服务，也不上报设备信息或使用统计；下载缓存在应用私有 cache，安装完成后自动清理。

## Liquid Glass 视觉

- 背景改为近黑中性底，只在角落里保留克制的淡色极光，并在底部渐隐，不再整页发绿发灰。
- 玻璃卡片、按钮、输入框改成更薄更透的冷灰玻璃；高光描边收细，阴影减弱，文字提亮，深色下对比更清楚；浅色主题保持干净的白色玻璃。
- 首页：状态圆点与右上角状态胶囊分开（在线显示延迟，连接中/重连中/已断开用颜色区分）；四个入口改为紧凑胶囊；命令输入框改为浮动标签（空时作占位、聚焦或输入后上浮），高度收紧；CMD/PowerShell 改为分段选择，发送改为实心强调色渐变；控制台与清空按钮重新对齐。
- 其它页面：分区标题、列表条目、开关、对话框、底部 Dock 的圆角与间距同步收紧；页面转场保留回弹但幅度更小。

## 说明

- 只改安卓端：Windows 接收端功能、协议、升级序列（3.18.8）保持不变；Windows 包显示版本同步为 3.20.0，需完整更新以保持版本一致。
- 双端版本 3.20.0，Android versionCode 73，沿用原签名。单元/集成测试全绿。

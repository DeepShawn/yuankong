# LanCmd 3.16.0

Windows 新增 **本机维护.cmd**。在电脑上右键以管理员身份运行，先确认停止当前接收端，再在电脑确认操作：

- 安装文件夹改名：限定同一父目录，失败尝试回退；只更新属于当前安装的自启动项，可确认打开新目录的可见启动面板。
- 本机卸载：校验发布清单，只移除对应程序文件；用户文件、升级 ZIP、配置、日志和恢复备份保留。卸载文件副本和操作进度独立保存，失败尝试回退。
- 普通文档批量修改／恢复最后修改日期：每批 1–100 个，通过电脑文件选择器选择并确认；保留原日期。恢复时跳过后来编辑、替换或存在身份冲突的文件。

工具在接收端停止且恢复工作进程退出后才允许维护。锁定／USB 策略恢复记录或未完成升级会阻止改名和卸载。摄像头、麦克风、网卡等设备状态及网络、防火墙、壁纸设置须由电脑管理员检查并按需恢复。

不提供远程、自动确认或无人值守维护模式；不修改接收端自身、系统／应用、日志／恢复记录的日期。维护工具会显示本机确认窗口。

独立记录位于 `%LOCALAPPDATA%\LanCmdMaintenance`，不自动清理。断电可能中断自动回退，请按[维护说明](../local-maintenance.md)查看原路径、备份与恢复步骤。

Android 仅同步版本为 3.16.0（versionCode 60），保留原签名及 miuix／KernelSU 外观。

发布文件：`LanCmd-3.16.0.apk`、`LanCmd-Windows-3.16.0.zip`、`SHA256SUMS-3.16.0.txt`。

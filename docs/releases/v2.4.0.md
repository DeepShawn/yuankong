LanCmd 2.4.0 统一了管理工具页面的界面样式，功能、通信协议和操作流程与 2.3.0 相同。建议同时更新安卓与 Windows 完整包，保持版本一致。

- 管理工具页面（任务管理器、注册表编辑器、电脑浏览器、应用锁、文本编辑、录音 / 录屏 / 摄像头、手势记录板）的输入框、下拉框和复选框改为与全局主题一致的样式：
  - 输入框和下拉框使用圆角描边底，聚焦时高亮描边；
  - 复选框选中时使用当前主题的强调色；
  - 控件内边距和间距加大，随所选主题色与背景色调变化。
- 仅调整外观，不改变任何功能、交互或网络协议。

Windows 接收端仅更新版本号至 2.4.0，接口与行为与 2.3.0 相同。升级前停止旧 Windows 接收端，替换完整目录；请保留原配置及 `device-policy.json`。安卓继续沿用发布签名，可覆盖安装 1.4.10 及之后版本。

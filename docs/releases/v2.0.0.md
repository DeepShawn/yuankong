LanCmd 2.0.0 是一次安卓界面焕新版本，功能、通信协议和操作流程与 1.9.0 保持一致。建议同时更新安卓与 Windows 完整包，以保持版本一致。

- 全新深色配色：更深的背景层次、柔和描边、薄荷绿主强调色与蓝色次强调色，错误、警告和成功状态色更清晰。
- 首页：新增品牌标题；连接状态点带光晕，延迟显示为等宽胶囊；「远程桌面」入口改为渐变卡片、图标底座和「进入」胶囊。
- 快捷入口：八个功能入口改为圆形图标底座和加粗标签；电脑音量、常用命令、U盘锁 / 设备、命令列表改为统一色块按钮。
- 控制台与命令输入：卡片加大圆角，日志区更深的底色；输入框聚焦时高亮描边，发送按钮改为渐变圆钮。
- 功能页：统一标题字体、状态提示条、按钮与卡片样式；搜索框和终端使用新输入样式；远程桌面的触控 / 键盘 / 终端切换高亮当前分区。
- 对话框：圆角卡片外观，确认按钮使用强调色，取消类按钮弱化显示；进程搜索框改为圆角。
- 虚拟键盘：按键配色、圆角与选中状态更新，布局和按键行为不变。
- 应用图标前景同步更新配色。

Windows 接收端仅更新版本号至 2.0.0，接口、设备管理、触屏暂停、命令计划等行为与 1.9.0 相同。升级前停止旧 Windows 接收端，替换完整目录；请保留原配置及 `device-policy.json`。安卓继续沿用发布签名，可覆盖安装 1.4.10 及之后版本。

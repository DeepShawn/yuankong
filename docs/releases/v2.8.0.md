# LanCmd 2.8.0

摄像头停用增加实际兼容处理，统一整理全应用导航、菜单和操作反馈。

- 首页可切换共享、文件、系统、自动化分类；工具名称显示两行，避免长名称截断。功能页右上角提供全部工具搜索，搜索“日期”“WPS”等可定位文件管理。
- 文件操作按打开预览、编辑属性、传输整理和高级操作分组；新建文本/脚本分组并保留编码选择。
- 最后修改日期：文件菜单 → 编辑与属性 → 最后修改日期，支持日期/时间选择和直接输入；按手机本地时区，保留原访问时间，支持延迟和文件版本校验。
- 摄像头、麦克风支持分类筛选、独立设备卡片和折叠详情；结果保留在原设备卡片，刷新后不会丢失。通用结果可直接点击展开，减少额外弹窗。
- 停用摄像头前释放 LanCmd 当前取帧与共享，停止相关录制并等待设备释放，期间阻止同类新采集；释放失败不继续停用硬件。
- 对 0x17 等常规接口的驱动否决，尝试 Windows 设备属性变更接口（SetupAPI），只操作所选设备并重新核实类别。不停用父控制器或扬声器，不终止其他应用，不自动重启。
- 只有读取的设备状态已经符合目标才报告成功；驱动要求重启时明确显示待重启。权限不足不重试为其他提权方式。

请同时更新 APK 和完整 Windows ZIP，先停止旧接收端再替换。接收端不新增应用或安装器弹窗；系统安全/隐私提示及硬件指示灯保留。

自动检查涵盖接口参数、备用流程、采集释放顺序、重启待生效、菜单和日期提交。实际摄像头与 WPS/USB 驱动仍需实机确认；第三方应用占用或驱动限制仍可能导致拒绝停用。

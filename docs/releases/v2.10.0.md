LanCmd 2.10.0 重构安卓界面排版，功能、通信协议和操作流程与 2.9.0 相同。建议同时更新安卓与 Windows 完整包，保持版本一致。

界面重构
- 新增统一的间距、字号、圆角标度和共用排版组件。此前各页面自己写字号和内边距，行距拥挤、层级不清；现在页面只描述内容结构，间距由组件统一给出。
- 列表记录改为结构化条目：标题、说明与状态标签分行显示，条目之间用细分隔线分隔，取代以往多行文字直接堆叠。已应用于 U盘与移动设备、应用锁、浏览器网址、录制文件、桌面窗口、命令列表等。
- 输入框与下拉框上方显示名称，不再只依赖灰色提示文字；列表为空时显示居中提示。
- 相关操作并排成组，不再每个按钮独占一行；删除、强制断开、结束所选进程等破坏性操作改用危险色描边与文字。
- 首页工具分类胶囊改为主题化样式：选中使用强调色底与文字，未选用表面色，带描边和圆角，跟随所选主题色与背景色调。
- 分组标题字体与字距统一；「全部工具」底部面板增加圆角顶部和抓手指示，工具项改为带描边、图标的卡片。
- 隐私设备的分类筛选改为明显的选中底色；摄像头与屏幕页面精简顶部说明，预览区域更大。

兼容性
- 所有按钮文字、无障碍描述和视图标识保持不变，操作流程与此前一致。
- 仅调整外观与排版，不改变任何功能、交互或网络协议。

Windows 接收端仅更新版本号至 2.10.0，接口与行为与 2.9.0 相同。升级前停止旧 Windows 接收端，替换完整目录；请保留原配置及 `device-policy.json`。安卓继续沿用发布签名，可覆盖安装 1.4.10 及之后版本。

LanCmd 2.10.0 继续美化安卓界面，功能、通信协议和操作流程与 2.9.0 相同。建议同时更新安卓与 Windows 完整包，保持版本一致。

- 首页工具分类胶囊（全部 / 共享与控制 / 文件与设备 / 系统与应用 / 录制与自动化）改为主题化样式：选中使用强调色底与文字，未选用表面色，带描边和圆角，跟随所选主题色与背景色调；胶囊之间留出间距。
- 首页分组标题字体、字距更统一精致。
- 「全部工具」底部面板增加圆角顶部和抓手指示；工具项改为带描边、图标的卡片按钮，分组标题与「文件操作延迟」按钮样式与全局主题一致。
- 仅调整外观，不改变任何功能、交互或网络协议。

Windows 接收端仅更新版本号至 2.10.0，接口与行为与 2.9.0 相同。升级前停止旧 Windows 接收端，替换完整目录；请保留原配置及 `device-policy.json`。安卓继续沿用发布签名，可覆盖安装 1.4.10 及之后版本。

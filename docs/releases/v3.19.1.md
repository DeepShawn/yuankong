# LanCmd 3.19.1

根据真机观感重做安卓 Liquid Glass 视觉；Windows 接收端功能未改。

- 背景：从大面积绿色泛光改为近黑中性底，只在左上/右侧/底部保留克制的淡色极光，并在底部渐隐，避免整页发绿、发灰。
- 玻璃：卡片、按钮、输入框改成更薄更透的冷灰玻璃；高光描边收细，阴影减弱，文字提亮，深色下对比更清楚；浅色主题保持干净的白色玻璃。
- 首页：状态圆点与右上角状态胶囊分开（在线显示延迟，连接中/重连中/已断开用颜色区分）；四个入口改为紧凑胶囊；命令输入框改为浮动标签（空时作占位、聚焦或输入后上浮），高度收紧；CMD/PowerShell 改为分段选择，发送改为实心强调色渐变；控制台输出与清空按钮重新对齐。
- 其它页面：分区标题、列表条目、开关、对话框、底部 Dock 的圆角与间距同步收紧；页面转场保留回弹但幅度更小。
- 只改安卓端：Windows 接收端功能、协议、升级序列（3.18.8）保持不变；Windows 包显示版本同步为 3.19.1，需完整更新以保持版本一致。
- 双端版本 3.19.1，Android versionCode 72，沿用原签名。单元/集成测试全绿。

发布文件：`LanCmd-3.19.1.apk`、`LanCmd-Windows-3.19.1.zip`、`SHA256SUMS-3.19.1.txt`。

LanCmd 1.5.1 修复启动失败、文件上传覆盖与 Android 缓存残留问题。建议两端一起更新。

### 修复

- **Windows 启动失败**：去掉启动命令开头多余的空格，避免 Python 把解释器本身当成脚本；完整保留空参数、中文、引号和反斜线，参数过长时明确报错。
- **上传数据保护**：`overwrite=false` 在提交时原子拒绝已有文件，保护上传期间新出现的同名文件；严格拒绝非法 Base64 和超量分块，提交失败会清理临时文件和会话。
- **Android 缓存残留**：未知大小文件在连接失败、服务端拒绝、读取异常或取消时均清理上传缓存，缓存复制期间支持取消。
- 更新协议、使用说明与发布流程，双端安装包均由 GitHub Actions 构建。

### 安装

- 手机下载 `LanCmd-1.5.1.apk`。沿用 1.4.10/1.5.0 发布签名，可直接覆盖安装；1.4.9 及更早版本需要先卸载。
- 电脑下载 `LanCmd-Windows-1.5.1.zip`。先停止旧接收端，再完整替换目录，双击 `Start.exe` 启动；配置保留在 `%APPDATA%\LanCmd`。
- `SHA256SUMS-1.5.1.txt` 包含两份安装包的 SHA-256。

本次未改变 1.5.0 的连接策略；文档已纠正旧的授权窗口与时限描述。

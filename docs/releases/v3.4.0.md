# LanCmd 3.4.0

安卓继续使用 Compose + miuix，重新排列首页和所有功能页的公共界面。默认进入命令控制台，底部切换共享、文件、系统与自动化；工具采用图标卡片。页头、输入区、列表、状态条、选择框与确认窗口统一外观，主题色完整覆盖 miuix 卡片与按钮。小屏下控制台可滚动，长结果可点开展开；文件和进程结果仍显示在页面顶部。键盘与手势板也更新外观。

浏览器改用稳定的浏览器 ID 和页面内选择窗口，避免列表刷新、切换 Windows 默认浏览器时索引失效或页面退出。

应用中心自动读取已注册的桌面程序和运行进程，支持搜索、启动、选择应用锁目标，以及冻结与解冻。没有可验证 EXE 的商店应用、系统组件等会说明限制。应用锁禁止指定文件再次启动；冻结只暂停现有进程，受保护进程会跳过。独立恢复进程持有目标句柄，接收端退出或心跳丢失时尝试解冻；请保留本机资源监视器等恢复途径，同时强制终止接收端和恢复进程无法保证恢复。

Windows 完整 ZIP 现在带有 `upgrade/README.txt` 和 `release-manifest.json`。把未来更高版本的完整 Windows ZIP 手动放入 `upgrade` 文件夹，然后从安卓「系统 → 本地升级」选择并确认。升级不联网下载；它校验文件清单、版本、架构和 SHA256，拒绝路径越界、链接和额外文件，在私有运行时中替换程序并保留回退备份。新版启动失败时尝试恢复旧文件并重新启动；断电、驱动故障或备份被删除仍可能需要手动恢复。SHA256 清单用于完整性检查，不是发布者数字签名。

录制、文件传输、脚本、延迟命令与文件任务须先结束，冻结应用会先尝试解冻。升级期间连接短暂中断，由既有连接管理器重连；重连成功后重新进入升级页查看状态。已有 3.3.0 及更早的 Windows 接收端不具备此功能，首次升级到 3.4.0 仍需手动完整解压替换。

新增「桌面背景」和图片文件菜单入口，支持本机 JPEG、PNG、BMP 及填充、适应、拉伸、居中、跨屏方式；图片复制到持久目录，设置失败时尝试恢复旧背景。

**虚拟桌面限制：**用户所指的是 Win+Tab 任务视图中的虚拟桌面。它们共享当前画面和输入，无法用 Windows 常规接口在主屏保持桌面 1 的同时，让手机独立完整控制未显示的桌面 2。本版未实现此项，也没有加入自动切走电脑主屏的替代行为。

Windows 不新增功能确认弹窗；系统权限、隐私指示、设备驱动提示和第三方应用自己的窗口仍由相应系统管理。实际双屏、摄像头和 USB 硬件行为需在目标电脑验证。

Android versionCode 40，沿用既有发布签名。Windows 支持 Windows 10/11 amd64 完整便携包。

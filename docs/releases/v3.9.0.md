# LanCmd 3.9.0

网络管控加入密码与管理员权限验证，支持设备多选批量启停。

- 进入「网络与蓝牙」先输入已设置的网络管理密码。Windows 接收端须已以管理员身份运行；密码不会自动提权。接收端独立校验全部网络读取、修改、配对回答和任务查询，未验证无法绕过页面直接调用。
- 只保留加盐密码校验值，不将实际密码写进源码、APK、日志或恢复数据。错误尝试限速，临时会话绑定原手机、有效 30 分钟；退出后再次进入需重新验证，可主动锁定。后台任务在锁定／断线后继续，重新验证只查询原任务。
- 网络与蓝牙硬件、网卡支持多选、全选、清空、批量启用／停用，每批最多 32 台。电脑逐项执行，一项失败继续其余项，手机显示每台实际确认结果。
- 热点客户端支持批量禁止／恢复联网。校验整组客户端和实际热点网卡后一次应用规则，保存失败恢复旧规则；支持批量移除离线客户端的限制。设备仍可能显示 Wi-Fi 已连接。

请同时更新安卓与完整 Windows 包，重启接收端。停用当前远控网卡会断开连接，可能需要在电脑端重新启用。该功能密码保护网络管理入口与网络 RPC，保留现有局域网 TCP 传输方式。

保留 miuix 主题、原生触控和本地 ZIP 升级；双端 **3.9.0**，安卓 versionCode **53**，沿用原签名。不新增 Windows 应用弹窗，必需的系统权限／安全验证保留。原生 API 回归不等同于已在所有无线硬件上实测。

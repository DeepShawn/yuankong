LanCmd 3.0.0 包含安卓界面重构、摄像头与屏幕预览全屏，以及 Compose + miuix 的首个页面迁移。

- 管理页面统一间距、字号、圆角与排版组件；列表按标题、说明和状态分层展示，输入框带名称，相关按钮成组，删除与强制断开等操作使用危险色。
- 摄像头与屏幕预览新增「全屏／退出全屏」，全屏隐藏工具栏与操作区，画面保持 FIT_CENTER 等比显示。返回键先退出全屏，旋转后保留全屏状态。
- 浏览器页面改用 miuix 的导航、卡片、输入框、下拉选择与网址条目，继续支持读取电脑浏览器、打开 HTTP/HTTPS 网址、在手机保存和删除常用网址。保存名称改为页面内输入。
- 迁移按页进行：目前只有浏览器页使用 Compose + miuix，其余页面使用现有 View 界面。浏览器页跟随系统深浅色；其余页面保留六种主题色和背景设置。
- Windows 接收端统一为 3.0.0，沿用 2.10.0 的接口与功能，不增加应用弹窗。系统安全、隐私提示和设备指示仍由 Windows 管理。

升级：安卓沿用 1.4.10 以来的发布证书，versionCode 增至 34，可直接覆盖安装。Windows 请先停止旧接收端，替换完整目录后重启，保留 `%APPDATA%\LanCmd` 下的配置、策略与设备恢复记录。

源码构建：Kotlin 与 Compose 编译插件为 2.3.20，miuix 为 0.8.8；构建和单元测试使用 JDK 21，应用字节码目标仍为 Java 17，最低系统仍为 Android 7.0（API 24）。

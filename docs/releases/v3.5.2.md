# LanCmd 3.5.2

修复安卓远程画面未屏蔽本地系统指针的问题。

- 鼠标或触控笔经过远程画面时，显式使用空指针，避免安卓默认箭头覆盖画面。普通工作区、切换模式、全屏及空预览保持一致。
- 保留手机圆形触控标记，手指按下立即显示；单击、双击、拖动、双指滚动沿用原有操作。
- 本次处理安卓系统指针；电脑系统光标继续由 Windows 3.5.0 起的输入会话隐藏机制控制，结束共享或断线后恢复。
- 保留 3.5.1 的文件搜索状态修复和现有 miuix 界面与主题。

Android versionCode 46，沿用原签名。Windows 仅同步版本号；已有 Windows 3.5.0 或 3.5.1，只需升级安卓即可获得本次修复。

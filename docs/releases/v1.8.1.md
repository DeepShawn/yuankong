LanCmd 1.8.1 优化安卓虚拟键盘，覆盖「远程按键」和「远程桌面」两个入口。

- 改为「字母 / 符号 / 功能」分区，按可用宽度排列，无需逐行横滑。保留数字、完整字母、F1–F12、导航与 OEM 标点按键。
- 固定显示 Ctrl / Alt / Shift / Win、Esc、Tab、空格、退格、Enter、方向键和 Delete。调整按键间距与圆角，突出 Enter。
- 修饰键选中后高亮，显示下一键组合，支持清除；输入一次、收起键盘或停止控制后清除状态。切换键盘分区保留待发送组合。
- 符号页补充常见上档符号，按 Windows 美式物理键位发送，自动合并 Shift。其他键盘布局如出现符号差异，可使用文字输入。
- 合并两个入口中重复的快捷键区域，远程按键页先显示虚拟键盘；桌面展开按钮同步显示「展开 / 收起」，展开后增大控制区并滚动至键盘，屏幕仍可查看。
- 保留当前共享和按键协议，Windows 接收端本次仅更新版本资源，后台提示行为不变。

验证包括窄屏与宽屏的按键边界和文字裁切、分区切换、修饰键高亮与清除、一次性组合、隐藏及停用状态复位、符号键协议、桌面展开收起，以及现有安卓集成和 Windows 回归。界面预览覆盖字母、符号、功能与组合键状态；真实手机的触感和可读性仍需设备体验。

安卓沿用原签名，可覆盖安装 1.4.10 及之后版本。Android 1.8.1 可配合 Windows 1.8.0 使用；完整 1.8.1 Windows 包也随本次发布提供。

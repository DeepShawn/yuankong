# LanCmd 3.12.0

- 修复占位文件点击确认创建偶尔没有反应的问题：确认期间暂停状态刷新，操作不会被忙碌状态丢弃。

- 修复手势记录板重新进入丢失当前记录：后台原子存储、旧命名手势迁移、自动恢复草稿、模式与延迟；底图显示最新桌面截图，可刷新后对照录制。
- 手机浏览器分享网页给 LanCmd，确认并选择电脑浏览器后打开；只传网址，不迁移手机浏览器登录状态。
- 应用中心新增自动刷新的运行中第三方软件和当前桌面窗口分类，支持最小化／还原。Windows 系统目录和无法验证的条目不会被归为第三方；Office 等微软应用保留。
- 新增文件密码锁：长期密码解锁，或按电脑本地指定时间自动解锁；手机断线仍有效。锁定前保存原权限备份，支持本机管理员恢复，拒绝系统文件和身份／权限冲突。

文件锁是 Windows 文件访问权限限制，并非内容加密。已有打开句柄不能撤销，请先关闭文件；到期自动解锁需要接收端运行，停机期间到期将在重新启动后处理。Windows 正常文件权限错误保留，无额外应用弹窗。

窗口管理使用最小化与还原、保留任务栏；不提供电脑不可见的独立应用操控或自动隐形启动。

请更新安卓与 Windows 双端，并完整替换 Windows 包后重启。沿用原 APK 签名、miuix／KernelSU 风格和本地 ZIP 升级。忘记文件锁密码时，在本机管理员控制台停止接收端后执行 `LanCmdCtl.exe --recover-file-locks`，保留 `%APPDATA%\LanCmd\file-locks.json`。

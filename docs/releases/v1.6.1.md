LanCmd 1.6.1 修复进程全选失效，并补充 Windows 管理员启动和实际权限显示。

### 修复

- 进程列表的「全选」不会再自动关闭弹窗；可切换为取消全选。「结束进程」保留列表，取消确认后选择不丢失。
- 仅选择当前筛选结果中的可操作进程，排除接收端自身及 PID 0/1；刷新清理失效选择，读取失败时清空旧列表，避免误操作。
- 手机进程页显示接收端实际权限；旧接收端缺少权限字段时显示未知。
- Windows `Start.exe` 新增「管理员启动 / 重启」：先经 UAC 授权，再停止普通权限接收端，启动继承管理员令牌的新实例。取消 UAC 时原连接继续。
- Windows 面板显示的是接收端的权限。停止失败时保留运行状态文件，不再误报已经停止。

### 使用与升级

1. 手机安装 `LanCmd-1.6.1.apk`，可覆盖安装 1.4.10 至 1.6.0 中使用现有发布签名的版本。
2. 电脑先停止旧接收端，再完整替换为 `LanCmd-Windows-1.6.1.zip`。
3. 在电脑打开新版 `Start.exe`，点击「管理员启动 / 重启」，允许 Windows UAC。手机可能短暂断开，随后自动重连；刷新进程页核对权限。

**管理员权限不等于系统最高权限。** Windows 仍会保护部分系统进程。管理员启动使用正常的 UAC 授权流程，普通开机自启仍使用原有权限。

### 验证

发布前运行 Android 进程选择、筛选刷新、取消确认、权限显示和请求取消回归，以及 Windows 原生令牌查询、停止状态文件与 UAC 取消分支测试。UAC 在原生测试中模拟批准和取消，不会自动点击真实系统授权窗口；实际设备上的 UAC 交互和受保护进程行为仍需设备验证。安装包签名与 SHA-256 在发布流程中核验。

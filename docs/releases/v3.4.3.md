# LanCmd 3.4.3

修复 Windows 3.4.2 便携接收端启动失败（退出码 1）。

- 接收端在初始化自身模块目录之前导入了 `storage_reads`。ZIP 自带的 Python 使用隔离模块路径，因此报 `ModuleNotFoundError` 并退出。现将模块路径初始化移到所有同目录导入之前。
- 增加隔离解释器的状态查询与实际监听、手机握手回归。
- Windows CI 新增发布包启动检查：直接下载本次构建的完整 ZIP，解压到包含中文、空格及特殊字符的目录，使用包内便携 Python 验证状态命令、GUI 启动器与真实接收端连接，以及 `start.bat --upgrade` 启动后 CMD 自动退出。检查失败不能发布。
- 保留 3.4.2 的本地 ZIP 更新、失败回退和安卓自动重连流程，不增加在线下载更新或 Windows 弹窗。

如果 3.4.2 已无法启动，安卓无法向它发起更新。请先退出旧接收端，手动解压完整 `LanCmd-Windows-3.4.3.zip` 覆盖原目录（包括 python 文件夹），再运行 `Start.exe`。保留 `%APPDATA%\LanCmd` 中原有配置，无须卸载。

Android versionCode 43，沿用原签名；安卓本次只同步版本号，3.4.2 手机端可以连接修复后的 Windows 接收端。

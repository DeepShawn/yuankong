# LanCmd 3.5.1

修复安卓文件管理搜索后修改文件，返回未筛选列表的问题。

- 同目录重命名、修改日期、文件任务完成及手动刷新时，保留搜索词、所在目录和列表滚动位置。
- 重命名后的文件不再匹配关键词时，保持原搜索条件并显示其余匹配结果或无匹配；不自动清空条件、返回全部文件。
- 主动切换目录会清空该目录筛选并从列表顶部开始。
- 页面重建保存搜索词和滚动位置；等异步目录数据加载后恢复，避免初始空列表吞掉位置。编辑子页返回仍停留在原文件管理搜索状态。
- 全盘搜索恢复关键词、范围、类型、排序、当前页及滚动。索引更新保留有效页，结果减少时只调整到仍有效的最后一页。

Android versionCode 45，沿用现有签名及 miuix 界面。Windows 仅同步到 3.5.1，接收端功能与协议保留 3.5.0；使用 Windows 3.5.0 的用户只升级安卓即可获得本次搜索修复。

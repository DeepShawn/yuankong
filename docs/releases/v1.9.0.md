LanCmd 1.9.0 更新触屏输入暂停、桌面程序、文件操作、命令计划和全屏显示，并包含新版虚拟键盘。请同时更新安卓与 Windows 完整包。

- 本机输入暂停包含键鼠与已识别的标准 HID 触屏。触屏由独立恢复进程临时禁用，保留本机 A R T E X + Ctrl + Delete、Ctrl+Alt+Del、手机恢复和共享心跳中断恢复。接收端退出、管道断开或恢复进程未收到心跳后重新启用由本次暂停的触屏；不改动原本禁用的设备、不设置永久禁用标记。触屏暂停需管理员权限，无法识别或暂停时返回错误，不显示暂停成功。
- 桌面页新增运行程序列表：显示窗口标题、进程名、PID，支持切换前台、最小化和正常关闭。操作前核对当前窗口与 PID；关闭不强制结束进程。
- 文件管理新增在电脑打开文件、应用或文件夹；手机可预览文本、常见图片和 ZIP 目录。图片最多 2 MB，文本最多前 128 KB。其他格式可在电脑默认应用打开。
- ZIP 解压到新文件夹，不覆盖已有目标；拒绝越界路径、符号链接、Windows 保留名称和大小写冲突，最多 2000 项、解压总量 512 MB。失败清理临时目录；不支持加密 ZIP 或 RAR/7z。
- 首页及桌面终端新增命令列表与延迟执行。手机保存多个命名列表，支持添加、编辑、调整顺序、删除、CMD/PowerShell 与每条 0–86400 秒等待。第一条从启动计时，后续在上一条结束后计时；单条最多执行 300 秒，失败仍继续下一条。Windows 端负责执行，手机断线不取消；可查看结果和取消未开始的命令。已开始的命令不因取消列表而撤销；接收端退出或重启不保留计划。
- 修复全屏后控制区仍占用高度的问题。全屏仅显示等比画面及退出按钮，恢复时还原工具栏和布局。画面按像素比例绘制，不受位图密度影响；绘制、光标与触控使用同一显示区域，保留黑边并忽略黑边点击，支持横竖屏。
- 虚拟键盘改为字母 / 符号 / 功能分区，保留固定 Win、Ctrl、Alt、Shift、Esc、Tab、Enter、退格、空格、方向键、Delete，以及数字、完整字母、F1–F12、Home/End/PageUp/PageDown 与标点。修饰键高亮、组合提示、清除及一次性作用；桌面展开时增大控制区。符号按美式物理键位发送，其他布局可使用文字输入。

Windows 接收端不新增操作通知、确认弹窗或控制台；授权、确认与错误在安卓显示。系统 UAC、SmartScreen、用户主动打开的程序窗口，以及程序自己的保存提示仍由 Windows 处理。

验证覆盖触屏恢复进程的管道中断、心跳丢失、部分失败恢复与原禁用状态保留；命令顺序和等待、取消边界、设备归属；ZIP 越界及覆盖防护、预览编码；窗口身份核对；安卓全屏占位、比例与像素绘制、触控回归、键盘各分区与命令和程序界面。真实触屏厂商驱动、窗口前台权限及真机显示体验仍需设备验证。独立恢复进程无法替代 Windows 驱动自身的可靠性；若驱动拒绝恢复，错误会返回手机，临时禁用可通过重新连接设备或重启恢复。

升级前停止旧 Windows 接收端，替换完整目录；请保留原配置及 `device-policy.json`。新增 `touch_guard.py`、`file_actions.py`、`desktop_apps.py`、`command_queue.py` 必须随包保留。安卓继续沿用发布签名，可覆盖安装 1.4.10 及之后版本。

# LanCmd 3.18.4

修复滚动公告打开闪退，并把循环选项改为直接选择。公告显示沿用 3.18.3：蓝色前缀固定，白色正文从右侧进入、向左滚动并被前缀裁切；颜色、尺寸、图标、位置和速度均不变。

## 闪退修复

希沃样式的手机预览多调用了两次 `Canvas.restore()`，打开保存过该样式的草稿后，首次绘制就可能破坏画布状态。现在只恢复该预览自身保存的状态，并验证普通打开、播放／暂停、展开编辑和旋转重建。

## 循环方式

进入“滚动公告 → 播放与延迟 → 循环方式”：

- **一直循环**：次数和时长均不限，可随时暂停或撤回。
- **循环 N 次**：填写 1–100；完整播放一轮后计一次，达到 N 轮停止。多条消息会全部播放完再计一轮。
- **按时长结束**：保留原有按时间结束功能，填写 1–3600 秒。

选择一直循环或循环 N 次会清除旧的时长上限，避免仍被旧配置提前结束。原有同时设置次数和时长的草稿会提示其上限，重新选择方式即可清除。空白、0 或超出范围的 N 会阻止发送。

设置只在确认发送／更新后影响电脑，恢复草稿不会自动发送。手机本地预览和电脑使用相同的轮巡时刻表；暂停不计时。Windows 接收端停止时公告仍会结束。

## 旧工具清理

按上一条要求，移除 3.16.0 增加的 `本机维护.cmd` 和 `local_maintenance.py`。新完整 Windows 包不再包含这两个文件；历史维护记录和回退备份保留。覆盖到已有目录可能留下旧文件，可在确认不再需要后手动删除这两个旧工具文件。

本次不改应用快捷控制、窗口管理、连接协议或其他接收端功能。

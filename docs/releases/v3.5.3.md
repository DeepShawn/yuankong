# LanCmd 3.5.3

修复电脑上的应用收到远程鼠标事件后重设自有光标，导致指针仍然出现的缺口。

- Windows 独立恢复进程临时连接光标窗口的输入队列，以自身的显示计数隐藏；应用继续调用 SetCursor 时也保持隐藏，结束时只撤销自身贡献并断开，不改写注册表或永久光标文件。
- 鼠标输入前同步准备目标窗口，拖动优先采用捕获窗口；跨窗口交接保留旧位置透明，继续校验状态，无法隐藏时停止本次控制。
- 安卓检查新的 cursor_visibility_input_queue 能力；旧电脑端会明确提示需要停止旧接收端并更新完整 Windows 包。
- 保留手机上的圆形触控标记、3.5.2 安卓空系统箭头和 3.5.1 文件搜索状态修复。
- 原生测试创建独立应用窗口，重设自有光标、接收真实 SendInput，并检查输入队列显示计数及退出恢复；发布 ZIP 内的实际接收端同样验证。这些测试覆盖 Windows 状态，目标电脑物理屏幕的最终效果仍需实机确认。

**更新必须包含 Windows：** 先停止旧接收端，完整解压替换 Windows 3.5.3 包再重新启动；手机安装 Android 3.5.3（versionCode 47）。仅更新手机不会替换电脑上已加载的旧代码。

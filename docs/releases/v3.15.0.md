# LanCmd 3.15.0

- 公告可先在手机播放、暂停、停止与重播，展开为编辑画布；拖动移动、拖四角缩放，支持 1×／2×／3× 放大预览与百分比精确位置。放大只影响手机，播放和编辑不会发送消息。
- 确认发送后，Windows 按主屏可用区域和 DPI 应用位置、大小，保留 ×／Esc 关闭与不抢焦点。最小 160×64 逻辑像素，窗口限制在可用区域内；不包含任务栏。手机字体度量与 Windows 可能不同，不承诺逐像素一致。
- 草稿与布局保存，旋转保留编辑状态；离开页面暂停本地预览，恢复不自动播放或发送。仍支持公告延迟、颜色、形状、字体、流动方式与次数／时长。
- 安卓初次进入和新页面加入 220 ms 淡入、位移与轻微缩放，遵循系统动画设置；恢复页面不重复，连接不等待动画完成。

自定义布局请同时完整更新 Windows 3.15.0 包并重启接收端；旧接收端保留预设功能，但不会接收新布局。分辨率／缩放变化后重新读取电脑尺寸。安卓 versionCode 59，保留原签名与 miuix／KernelSU 风格。

# LanCmd 2.7.0

Office 文件增加手机 WPS 查看/编辑、明确回传与电脑 WPS 打开；新增延迟文件操作与修改日期。文件管理、任务管理器现在支持多选，执行结果直接显示在页面顶部，展开可看逐项明细。

- 文件：全选、反选、清空；批量复制、移动、删除和下载，支持文件夹。手机目标通过系统目录选择器指定，同名文件和文件夹不覆盖。
- Windows 批量文件任务支持进度、取消和文件版本校验；离开页面继续执行，重新打开“文件任务”查看。跨卷移动如源清理失败，保留复制结果并明确报告。
- 进程：批量结束，按 PID 和创建时间绑定，刷新保留有效选择；关键或受限进程自动跳过。取消只停止后续请求。
- 占位文件：在文件管理中增加直接入口，支持真实占用 0–500 GB、隐藏与系统属性、任务进度和取消清理。
- USB 强制断开：增加接收端版本/能力检查；旧进程或混用旧模块引起的“无效的设备管理操作”提示完整更新。断开前停止本应用相关文件任务，失败后正确恢复可用按钮。

删除和结束进程仍需操作前确认；结果不另弹窗。Windows 不新增应用提示，保留系统安全与隐私提示。

请同时更新 APK 与完整 Windows ZIP，停止旧接收端后再替换并重启。强制断开是禁用设备，可能仍有供电，正在写入时可能丢失数据；优先安全弹出，可在设备管理恢复。

自动检查覆盖 Android 界面/协议与 Windows 原生功能；实际 USB 驱动和触控硬件仍需在目标电脑验证。


Office：支持 DOC/DOCX、PPT/PPTX、XLS/XLSX、WPS/ET/DPS、PDF 等，使用手机安装的 WPS（未安装时选择其他办公应用）。编辑的是手机副本，保存并返回后点击回传；若 WPS 另存为，请先选择另存文件。电脑原件有变化时拒绝覆盖，手机副本保留。电脑 WPS 需已安装并完成初始化，查找已注册的组件；默认应用打开也保留。

“在当前窗口下方打开”请求不激活新窗口，并对本次新建且可识别的窗口调整层级；不影响已有窗口。应用自行置顶、复用已有窗口或系统限制时不能保证一直在后面，不会隐藏窗口或拦截系统提示。

文件管理搜索栏的延迟按钮设为 0–86400 秒。电脑端新建、重命名、删除、复制/移动、解压、打开、预览、文本读写、脚本和占位创建支持接收端计时；“延迟计划”可取消尚未开始的操作。已开始操作不能撤销。计划保留至接收端退出，Windows 重启不会续跑。上传、下载和手机 WPS 需手机保持连接和应用存活，倒计时可随取消传输停止。

修改日期按手机本地时区输入，保留原访问时间；延迟执行前检查文件版本。消息使用输入的标题，不加 LanCmd；默认 CMD 从 Windows System32 执行，继续无控制台窗口。0x17 表示驱动否决设备停用，先关闭占用和本应用共享/录制；驱动仍拒绝时报告失败，不禁用父控制器替代。

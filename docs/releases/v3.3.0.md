LanCmd 3.3.0 把安卓端全部 19 个页面重写到 miuix（MIUI 风格的 Compose 组件库）。这是一次界面重构：命令协议、RPC 请求结构、确认流程、版本冲突校验与权限检查都没有变化，Windows 接收端没有功能改动，只同步版本号，不必为此更新接收端。

重写的页面：首页、远程桌面、文件管理、文件搜索、文本编辑、命令列表、任务管理器、注册表编辑器、运行中的桌面程序、应用锁、浏览器、隐私设备、U盘与移动设备、录音／录屏、屏幕与摄像头预览、手势记录板、Office 文档、远程按键、发送消息、隐藏系统占位文件。排版集中在一套组件里（页面骨架、分区卡片、列表条目、操作按钮、输入框、进度条），各页面只描述内容，留白与圆角统一给出。「外观主题」里的 6 种主题色 × 4 种背景色调继续生效，Compose 页面用与原先同一套颜色标记构建配色。

旧的 View 组件层（`FeatureActivity`、`Ui.kt`、`ToolGrid`）及首页的两个 XML 布局已删除。远程画面、摄像头画面、手势画板和虚拟键盘仍是自绘 View，通过统一的宿主节点嵌入 Compose；每个节点自带容器，避免同一个 View 在全屏与非全屏之间被反复装卸。共用弹窗（进程列表、电脑音量、外观主题、常用命令、文件预览、目录选择、脚本任务、工具搜索）仍是系统对话框，其中的输入框、下拉框与按钮改用与页面一致的外观。

几处刻意的交互调整：

- 文件管理与文件搜索的单项操作，由长按列表行弹出的菜单改为列表弹窗，分组（打开与预览／编辑与属性／传输与整理／高级操作／删除）保持不变。Compose 页面没有稳定的菜单锚点，改为弹窗后入口在小屏上也不会被截断。文件修改日期弹窗仍带日期与时间选择器。
- 首页右上角的溢出菜单同样改为列表弹窗，条目与原先一致。
- 屏幕／摄像头预览和远程桌面的全屏改为页面状态，不再逐个隐藏控件；全屏仍只保留等比画面与退出按钮，返回键先退出全屏。
- 文本编辑去掉了「键盘弹出时隐藏页头」这一纯 View 的处理，可滚动的页面不再需要它。编辑草稿、版本冲突检查、自动保存与退出确认均未改变。
- 占位文件任务在进度未知时不再显示进度条，由条目标题说明当前阶段（正在检查目录与磁盘容量、正在快速分配真实空间等）。不确定进度在 Compose 下是一条持续动画，开销不划算。

Android versionCode 39，沿用发布签名。122 项单元测试全部通过，覆盖各页面的操作入口、RPC 请求结构与确认流程。界面观感建议装机实际查看。

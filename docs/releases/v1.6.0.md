LanCmd 1.6.0 新增统一远程桌面：在安卓手机上查看电脑屏幕，并直接通过触控操作鼠标；键盘和命令终端也整合到同一页。

### 新功能

- 首页新增「远程桌面」卡片，原「屏幕」入口同样进入工作台；点击「开始共享」后才建立会话。
- 屏幕上轻点单击、双击、长按右键、单指拖动、双指滚动。坐标按真实画面映射，黑边不会触发点击，支持多显示器桌面。
- 同页切换鼠标按钮、常用组合键、文字输入和 CMD/PowerShell 终端；支持全屏与横屏左右布局。
- 画面、键鼠和终端使用独立连接，长命令不会卡住触控。停止、断线或退出页面会关闭专属会话并释放拖动中的鼠标按键。

### 安装

- **两端都需要升级**：手机安装 `LanCmd-1.6.0.apk`，电脑完整解压 `LanCmd-Windows-1.6.0.zip`，停止旧接收端后使用新版 `Start.exe` 启动。
- Android 沿用现有发布签名，可覆盖安装 1.4.10、1.5.0 和 1.5.1；更早版本需要先卸载。
- 两份安装包的 SHA-256 见 `SHA256SUMS-1.6.0.txt`。

### 验证与范围

回归覆盖触控坐标与黑边、拖动取消、双指滚动、旧接收端升级提示、长命令期间独立画面与输入、共享停止清理，以及 Windows 鼠标输入结构与参数校验。发布前运行完整 Android 和 Windows 原生测试，并核对签名、打包源码与校验值。

触控映射为鼠标操作，使用 JPEG 定时预览；不是 Windows 原生多点触屏或高帧率视频。停止等待终端结果不会撤销已经在电脑上执行的命令。真实手机触感、网络延迟、不同显示器缩放与 UAC 窗口仍需实际设备验证。

# LanCmd 3.18.5

本次完成普通文件只读属性编辑，并修复维护页打开／刷新卡住的状态读取。隐藏、系统属性仅可查看；未增加隐藏文件或静默自删除控制，也没有修改原有维护执行路径。

## 文件属性

在文件管理菜单中选择“文件属性”，查看只读、隐藏和系统标记，并保存只读选择。

- 支持普通文件和文件夹，保留其他属性，不改内容、创建／访问／修改日期或 ACL 权限，不递归修改子项。
- 文件夹的只读标记不等于文件夹权限锁，不能用于禁止子文件写入。
- 系统文件、接收端及恢复记录仅可查看；拒绝链接／重解析点、多个硬链接、文件身份变化或已被其他程序改动的属性快照。
- 属性读取不等待全局延迟；只读修改沿用文件延迟设置。修改后刷新同一目录，保留搜索条件。

## 维护状态诊断

原页面依次等待维护日志和日期记录扫描，慢查询会占用主连接并让页面长时间处于忙碌状态。新页面只通过独立查询连接使用只读诊断接口，最多等待 8 秒；可以取消、看到错误后重试或直接返回。

Windows 在一个独立后台工作线程中扫描，RPC 立即返回加载状态或缓存，不等待磁盘完成。每个目录最多扫描 256 项、加载本次扫描中较新的 48 个文件，单个文件最多 256 KiB、总读取预算 2 MiB；大日志只读尾部。预算、耗时、权限、损坏或链接导致的不完整结果会显示警告，原文件保留。

尾部未看到完成事件仅表示状态未知，不证明维护助手仍在运行。诊断不完整时不允许触发维护操作。取消／退出只关闭本页查询连接，主连接保留；本次没有改动目录改名、重启、自删除、日期修改的执行逻辑。

新属性和诊断接口需要完整更新并重启 Windows 接收端。双端版本 3.18.5、Android versionCode 67，沿用原签名和 miuix／KernelSU 外观。

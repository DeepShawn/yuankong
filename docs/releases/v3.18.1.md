# 3.18.1 — 滚动公告改成真正的一体机样式（按截图逐像素校准）

3.18.0 的“希沃样式”方向错了：我做成了居中的圆角浮动条。对照真实的一体机「消息通知」
截图重做后，它应该是一条**通栏的深色带**：没有圆角、没有阴影、没有徽标底框、没有分隔线、
没有关闭按钮，蓝色描边喇叭 + 蓝色「消息提醒：」+ 白色正文排在同一行里。

## 一、这次是怎么定下来的

拿到的参考图是一张 640×360 的效果预览。用桌面图标（16 px，即 1/3 缩放的 48 px）标定后确认
它其实是 1920×1080 桌面的 1/3 缩略，于是所有尺寸都能换算成“屏高的几分之几”，
在任何分辨率上比例都不会变：

| 项目 | 参考图实测（640×360） | 写入规格 |
|---|---|---|
| 条高 | 52 px（y=168…219） | 52/360 屏高 |
| 距屏幕顶 | 10 px | 10/360 屏高 |
| 左内边距 | 19 px | 19/360 屏高 |
| 喇叭图标 | 20×19，描边 2 | 20/360，描边 2/360 |
| 图标到文字 | 8 px | 8/360 屏高 |
| 字号 | 字宽 19 px | 19.5/360 屏高 |
| 字重 | 笔画 2 px ≈ 0.09 em | 常规（不是粗体） |
| 背景 | 顶 #020914 → 底 #040E1C | 竖向渐变 |
| 喇叭 / 前缀 | #559BE2 | 同一色 |
| 正文 | #FFFFFF | — |

## 二、具体改动

- **通栏**：窗口就是整条屏幕宽，贴着屏幕顶部下图 10/360 的位置，没有左右留白。
- **纯色带**：删掉圆角、阴影、徽标方块、分隔线、× 与两端淡出，只剩一条极淡的竖向渐变。
- **喇叭**：改成描边图标（左侧小方箱 + 锥形 + 两道声波弧），不再是白色实心加方底。
- **一行文字**：前缀与正文在同一行里，前缀带全角冒号并着蓝色，正文白色，常规字重；
  整行一起滚动。
- **短消息不滚**：文字短于可用宽度时静止左对齐（参考图就是这样），只有超长才从右侧进场。
- **速度随字号**：2.4 个字号宽／秒（1080p 约 130 px/s），不再写死像素速度。
- **去掉 ×**：参考图的条上没有关闭按钮。电脑端仍可按 Esc 关闭，手机端仍有「撤回」。
- 3.18.0 的逐像素 alpha 分层实现一并删除——整条不透明，直接 BitBlt 到窗口即可，
  代码更短也更快（每帧只画字）。

## 三、两端仍然共用一张表

`windows/announcement_seewo.py` 是唯一来源，`AnnouncementSeewo.kt` 是镜像，
`tools/test_announcement_seewo.py` 会解析两边常量并断言完全一致；窗口内坐标、
喇叭多边形的每个顶点、滚动公式也都逐项对齐。

离线校对工具也换成了新规格，可以直接和截图叠图：

```bash
python tools/render_announcement_preview.py bar.png --text "今天下午放学后，请各班班长安排全体学生进行大扫除。"
python tools/render_announcement_preview.py desk.png --desktop 1920x1080 --text "..."
```

按同样的文案渲染后，文字起点与参考图都在 640 宽的 46 px 处，行尾 592 vs 608（差 2.7%，
来自预览用的 Noto CJK 与微软雅黑的字宽差异；Windows 上用的是雅黑）。

## 兼容性

- 双端 3.18.1，Android versionCode 63，保留原签名与 miuix／KernelSU 外观。
- `announcements` 的 `style` 字段与 3.18.0 相同（`classic` / `seewo`），`seewo` 的锁定值变了：
  `shape=rectangle`、`bold=false`、`opacity=100`，位置/尺寸/字号/速度全部由屏高推导，
  `config` 里的 `font_size`、`speed`、`width`、`placement` 对希沃样式不再生效。
- 经典样式（`classic`）完全不受影响，仍是 3.16 的圆角/阴影/× 那一套。
- 只换 EXE 或只更新安卓都会报缺模块或“未知命令”，须整包更新。

## 已知边界

- 参考图是效果预览（图上自己写着“示例图片仅供参考”），不同版本的希沃可能略有差别。
  如果手上的版本与此表不同，改 `announcement_seewo.py` 顶部常量并同步 Kotlin 常量即可，
  单元测试会拦住两边跑偏。
- 屏幕顶部 10/360 的间隙是照参考图做的；如果你们的机器上条是紧贴顶边的，
  把 `TOP` 改成 0 即可。

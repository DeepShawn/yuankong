# LanCmd 3.11.0

全景录制：把电脑桌面、摄像头小窗、系统播放声音和麦克风环境声同步录入一个 MP4。

- 「全部工具 → 全景录制」，默认选择全部四项；小窗可放四个角落，按摄像头原比例显示。也可关闭任一音频源，普通屏幕／摄像头模式同样能录系统声音。
- 系统声音采用 Windows WASAPI loopback，录制开始时的默认播放设备；两路声音混合为 48 kHz 双声道 AAC。录制音量分别为 0–200%，只影响文件，另有电脑扬声器音量入口供手动调整。
- 没有播放声音时填入静音，采集失败或默认输出设备变化时明确结束，不替换成其他音源；尽力封装已采集内容。受保护音频及系统不允许采集的内容可能无法录入。
- 保留 1–3600 秒时长、约 1 GB／可用空间限制、手动停止、手机下载和播放。手机断线或退出页面仍继续，退出 Windows 接收端则停止并尝试封装。
- 录制范围在手机确认。全景正确占用桌面、摄像头和选中音源；禁用硬件前先停止对应录制。系统声音单录不占用麦克风；旧录制 EXE 不会被当作支持全景的新版。

请完整更新双端并重启 Windows 接收端，含新版 **LanCmdRecord.exe**。双端 **3.11.0**，安卓 versionCode **55**，沿用原签名、主题、键盘修复及热点定时。不新增 Windows 应用弹窗；系统隐私权限与设备使用指示保留。测试包含合成画面／音源的真实编码解码，实际摄像头和声卡兼容性仍以目标电脑为准。

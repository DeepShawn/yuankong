LanCmd 3.1.0 优化安卓导航与自适应布局。

- 首页工具按屏宽与字体大小自适应排列，手机以两列为主，宽屏最多四列，大字体下可减少列数。
- 首页新增全部工具搜索入口，调整工具区与控制台的空间比例。
- 共用操作组根据文字和可用宽度切换横排、竖排；短标签筛选保持紧凑。
- 工具导航区分标题与说明的字号、字重和颜色。文件、进程与设备的结果反馈位置保留。

本次延续 3.0.0 的分阶段 miuix 迁移：浏览器页使用 Compose + miuix，其余页面使用现有 View 界面。

Android versionCode 35，沿用原发布证书，可覆盖安装。Windows 同步版本号，接口与功能沿用 3.0.0；升级前停止旧接收端，替换完整目录，保留 `%APPDATA%\LanCmd` 下配置和设备恢复记录。

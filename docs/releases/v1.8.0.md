LanCmd 1.8.0 新增 U盘锁与移动设备管理，请同时更新安卓和 Windows。

- 安卓首页新增「U盘锁 / 设备」入口：查看 USB 存储、移动硬盘和 USB MTP/PTP 手机，显示设备名称、容量、挂载路径及设备 ID。
- U盘 / Windows 可移动磁盘支持禁止读写、只读和解锁；MTP/PTP 便携设备支持锁定与解锁。按设备类别应用，重启后保留。
- 解锁恢复 LanCmd 修改前的注册表策略；恢复记录存放在原配置目录的 `device-policy.json`，升级时请保留。检测到其他程序修改策略时停止覆盖。
- 安全弹出前重新枚举设备，拒绝任意设备 ID、已断开设备和系统磁盘。设备忙或权限不足时返回失败，不强制卸载。
- 操作确认与结果显示在安卓；Windows 不新增应用弹窗或通知，PowerShell 查询不显示控制台，设备弹出拒绝原因直接返回手机。Windows 必需的 UAC、本地主动操作和主动发送消息的现有行为保留。
- 策略修改及弹出要求电脑接收端已获管理员权限；标准权限可查看。安卓页绑定原连接，切换电脑或连接失效后不会向新电脑发送原页面的操作。

策略保存不代表已连接设备立即受限。请重新插拔设备，必要时重启 Windows；Windows 域策略、用户策略及其他设备限制仍可能生效。部分 USB 移动硬盘被 Windows 识别为固定磁盘，未必受可移动磁盘策略限制。此版本不管理手机系统、应用或企业 MDM。

升级：先停止旧 Windows 接收端，再替换完整目录并启动；新包包含 `device_management.py`。安卓沿用原签名，可覆盖安装 1.4.10 及之后版本。需要修改策略时，在电脑 `Start.exe` 点击「管理员启动 / 重启」并允许 UAC。

验证覆盖策略恢复、写入失败回滚、原有系统限制保留、外部策略冲突、管理员权限、弹出白名单和系统盘保护、Windows 原生只读枚举与无效设备错误，以及安卓确认、连接切换和界面回归。真实 U盘、移动硬盘及各厂商 MTP/PTP 驱动的策略生效和弹出兼容性仍需实机验证。

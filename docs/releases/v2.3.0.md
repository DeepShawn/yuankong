LanCmd 2.3.0 新增文本编辑、脚本运行、应用锁、独立任务管理器、注册表编辑器、浏览器卡片，以及摄像头/麦克风设备管理。请同时更新安卓与 Windows 完整包。

- 文件管理「新建」支持文件夹、TXT、BAT、VBS、CMD、PS1、Markdown、JSON、INI 及自定义扩展名的文本文件；创建后直接进入编辑，不会自动执行。文本文件上限 512 KB，支持 UTF-8、UTF-8 BOM、GBK、GB18030、带 BOM 的 UTF-16 LE/BE，支持 CRLF/LF/CR 和保留混合换行。
- 文件菜单「编辑文本」直接在安卓读写电脑文件，支持手动保存、可选停止输入 1 秒后自动保存、另存为及手机私有草稿。保存前核对读取时的文件版本；发生冲突或编码错误时停止自动保存并保留内容。Windows 使用 ReplaceFile 保留原文件权限和备用数据流；链接、二进制及超限文件不在线编辑。文本编码自动识别有歧义时可选择编码重新加载。
- BAT/CMD/VBS 文件菜单新增运行按钮，手机确认后使用隐藏的 CMD/CScript 运行器执行；输出和错误显示在安卓「脚本任务 / 运行记录」。每次最长 300 秒、最多同时 4 个任务，每路输出保留 8 KB，支持取消。关闭手机任务窗口不停止脚本，退出接收端停止仍在运行的任务；取消不能撤销已执行的操作。VBScript 需要系统仍安装且允许使用该组件，不自动更改系统脚本策略。
- 首页独立卡片：任务管理器、注册表编辑器、浏览器、应用锁。工具区可滚动，软键盘弹出时收起工具区，为控制台和命令输入保留空间。
- 任务管理器使用 Windows 原生进程接口，显示 PID、内存、CPU 采样、可见路径，支持搜索和排序、在文件管理定位、进入应用锁及结束选定进程。结束前核对创建时间以避免 PID 复用；禁止结束关键进程、LanCmd 自身和受保护组件。结束可能丢失未保存内容，权限不足不会自动弹 UAC 或提升权限。
- 应用锁对指定 EXE 添加当前 Windows 用户的执行拒绝权限，阻止该文件后续启动，不强退已运行程序。原权限与文件身份保存在 `%APPDATA%\LanCmd\app-locks.json`，重启接收端后仍可解锁。不能锁定 Windows 系统目录和 LanCmd 自身；解锁前检查文件身份和外部权限变化，不覆盖冲突。影响所选文件，不追踪复制、重装或替换后的新文件；尝试启动被锁程序时 Windows 可能显示拒绝访问提示。通常需要管理员文件权限，保留备份直至全部解锁。
- 注册表编辑器在安卓浏览 HKCU/HKLM/HKCR/HKU/HKCC 的 32/64 位视图，分页读取子项和值；支持新建子项、删除空项和 REG_SZ/EXPAND_SZ/DWORD/QWORD/MULTI_SZ/BINARY 值的增删改。写值前核对版本并备份到 `%APPDATA%\LanCmd\registry-backups`，可从最近备份恢复，外部值变更时停止覆盖。仅使用现有权限，不启动 Regedit.exe，不递归删除非空项，不支持在线编辑其他类型或大值。
- 浏览器卡片可选择默认浏览器或注册的 Edge/Chrome/Firefox/Brave/Opera，发送 HTTP/HTTPS 网址在电脑打开，手机可保存常用网址。不会读取浏览器历史或标签页；打开网页会正常显示浏览器窗口，不自动绕过浏览器安全检查。
- 「更多 → 隐私设备」以及设备管理、录制/摄像头页面可管理摄像头和麦克风。列出支持的 PnP 摄像头与录音端点，管理员可启用/停用，停用可能跨重启保留；麦克风可单独静音/取消静音。停用影响电脑所有应用并可能中断录制。设备启用不会授予应用隐私权限，不停用声卡控制器或扬声器；旧设备或特殊驱动可能不支持，状态不确定或失败时返回安卓错误。

LanCmd 新管理操作不新增 Windows 应用通知或确认弹窗；系统隐私提示、硬件指示灯、系统访问拒绝提示和安全限制仍然保留。主动打开网页、启动程序以及脚本自行创建窗口属于这些操作的正常效果，不保证其他应用不会显示自己的窗口。

自动检查覆盖文本编码/冲突、真实 Windows 权限拒绝与恢复、注册表读写恢复、脚本特殊路径运行与取消、进程身份、隐私设备校验及安卓界面。实体摄像头、麦克风和第三方驱动的启停仍需实机验证。升级前停止旧接收端、替换完整目录，保留全部配置、`device-policy.json`、`app-locks.json` 及注册表备份；安卓沿用原签名。

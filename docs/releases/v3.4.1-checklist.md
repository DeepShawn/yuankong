# 3.4.1 修复与验证清单

范围包括本轮所有已报告问题；各项只有在回归验证后才勾选。验证为自动化测试与测试环境预览，不代表已在用户的 U 盘、触屏驱动上实测。

- [x] 远程工作区：画面等比显示，默认操作栏占 52%，键盘展开占 72%；横竖屏分隔条可调整。
- [x] 触控显示：手机圆形落点标记保留，电脑指针在可见触控模式临时隐藏；切换模式、进入子页、停止、失联恢复。
- [x] 文件夹操作：右侧操作按钮和长按可改名，普通点击继续进入目录，成功刷新并反馈。
- [x] 文件多选：逐项勾选、选中背景、反选、取消及同数量替换实时刷新，批量复制、移动、删除与下载保留。
- [x] 进程多选：同样显示即时勾选，身份复用及受保护进程校验保留。
- [x] 文件输入：重命名、新建文件自动调起输入法，重命名全选原名称，非法名称不发送。
- [x] 占位文件卡住：容量查询按盘隔离；目录读取有等待上限且重试共用原读取；慢盘不阻塞整个 RPC；目录已知时优先显示；大目录排序移出主线程，占位历史任务使用独立滚动与惰性列表。
- [x] 占位创建回归：0–500 GB 实际空间、稳定/快速模式、容量余量、取消、失败及退出清理。
- [x] 应用冻结无结果：可查询后台任务与结果，冻结/解冻状态不再等待全量应用扫描；冻结进程的创建时间、路径、保护范围、独立恢复保留。
- [x] 应用列表关闭：安卓确认后结束选定 EXE 的已验证进程，跳过关键进程和接收端自身，报告部分失败，不额外弹 Windows 提示。
- [x] 应用列表刷新：后台单任务扫描、缓存可读、冻结记录不被慢扫描遮住；加载中仍可返回与操作已有条目。
- [x] UI 风格：KernelSU 参考风格与 miuix 经典风格可选，12 色、4 深色和 2 亮色背景保留。
- [x] 工作区域：文件、搜索、进程和文本编辑独立分配剩余高度；压缩选择器与装饰，不缩小主要操作区域。
- [x] 导航回归：内部子页面往返保留共享和授权连接；真正离开应用按现有规则结束共享并恢复输入。
- [x] Android 全量测试、签名及 APK 版本校验。
- [x] Windows 原生测试、完整 ZIP 模块清单与本地升级校验。
发布门禁：合并保留验证提交；发布工作流强制核对标签与两个成功构建的源提交一致，并核对 APK 签名来源校验、测试报告、Windows 清单与 SHA256。

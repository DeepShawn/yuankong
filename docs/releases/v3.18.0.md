# 3.18.0 — 滚动公告改为与一体机一致的“希沃样式”

3.18.0 只做一件事，但做得彻底：把原本“参考公开示例”的跑马灯，换成一套锁定的、
逐像素规定的**希沃样式**，Windows 端与安卓预览共用同一张尺寸表。

## 一、样式是锁定的，不是一堆滑杆

手机在「滚动消息与公告 → 内容与预设」打开「希沃样式（锁定外观）」后：

| 项目 | 取值 |
|---|---|
| 位置 | 主屏可用区域顶部，居中 |
| 宽度 | 可用宽度 − 48，最多 1760 逻辑像素（1920 屏约 92%） |
| 高度 | 56 逻辑像素（窗口含 8 像素阴影留白，共 72） |
| 圆角 | 10，抗锯齿，由 alpha 蒙版实现（不是窗口 region） |
| 背景 | 竖向渐变 #12324F → #071522，顶部 1 像素高光 #5E9FD0 |
| 徽标 | 30 × 30 圆角 8 的蓝色渐变方块 + 白色喇叭（锥形 + 两道声波弧） |
| 前缀 | 20 号粗体 #8FD8FF，前缀列宽由字数估算，右侧 1 像素分隔线 |
| 正文 | 22 号粗体 #FFFFFF，向左匀速 132 逻辑像素／秒，循环间隔 64 像素 |
| 两端 | 左右各 20 像素淡出，文字溶进当前渐变色（按 8 段取色，无接缝） |
| 关闭 | 右上角 ×，点击热区 36 像素 |
| 阴影 | 6 层同心圆角矩形，最外 0x6E 黑，向内收敛 |

只有**正文、前缀、播放次数、显示秒数**可改；其余字段即使手机带着旧草稿发上来，
`validate()` 也会重写成上表的值并忽略自定义位置，避免“改完就不像学校的通知条”。

## 二、Windows 改为逐像素 alpha

旧实现用一个 32 位位图 + `SetLayeredWindowAttributes` 给整窗一个统一透明度，
画不出柔和阴影和抗锯齿圆角。新实现：

- 用 `CreateDIBSection` 建 32bpp 自上而下 DIB，`UpdateLayeredWindow` 呈现，
  真正逐像素 alpha；
- 静态层（阴影 + 渐变条 + 徽标 + 前缀 + 分隔线 + ×）只画一次，缓存成预乘 BGRA
  和 alpha 蒙版；
- 每帧只复制静态层、让 GDI+ 画一行滚动文字，再从蒙版恢复 alpha 通道（一次切片赋值）。
  文字永远画在条内，所以蒙版始终有效，也不需要逐像素运算；
- `window_rect()` 的对外契约不变：手机看到的矩形就是 `GetWindowRect` 的结果，
  阴影留白包含在这个矩形内。

经典样式（`style: "classic"`）走原来的 `Surface` 路径，行为与 3.17.0 完全一致。

## 三、两端一致

`windows/announcement_seewo.py` 与 `android/.../AnnouncementSeewo.kt` 是同一张表，
`tools/test_announcement_seewo.py` 会正则解析 Kotlin 文件并断言每个常量一致；
前缀列宽用同一套字宽估算（CJK 1 em、拉丁 0.55 em），保证正文在手机预览和电脑上
从同一个像素开始。

安卓预览按相同顺序绘制：阴影 → 圆角渐变条 → 顶部高光 → 徽标 → 前缀 → 分隔线 →
× → 滚动正文（两端淡出）。暂停或播放完毕时正文居中显示，便于编辑时看全文。

## 四、可以自己校对

```bash
python tools/render_announcement_preview.py bar.png --scale 2 --center
python tools/render_announcement_preview.py desk.png --desktop 1920x1080 --center
```

这是离线预览工具（不是接收端的一部分），用同一张尺寸表渲染 PNG，可以直接和
教室一体机的截图叠起来对比。字体用系统的 CJK 字体代替微软雅黑，字形只能参考；
**盒子位置、间距、颜色、滚动偏移是精确的**。如果你手上的希沃版本与这张表有差别，
改 `announcement_seewo.py` 顶部的那二十几个常量（并同步 Kotlin 常量）即可，
测试会阻止两边跑偏。

## 兼容性

- 双端 3.18.0，Android versionCode 62，保留原签名与 miuix／KernelSU 外观。
- `announcements` 的 `config` 新增 `style: "classic" | "seewo"`，默认 classic；
  旧手机不传该字段时行为不变。
- 新增模块 `announcement_seewo.py`、`announcement_layer.py`，须随整包更新；
  只换 EXE 会在启动时报缺模块。
- 手机端关闭「希沃样式」即回到 3.17.0 的自由外观（位置、尺寸、配色、字体、动效全开）。

## 边界

- 样式表按 1920×1080 / 96 dpi 的常见教室一体机校准；4K 或 125% 缩放下所有数值
  按 dpi/96 等比放大，比例不变。
- 淡出是按背景渐变分 8 段近似的，肉眼无接缝，但不是逐像素数学精确的 alpha 场。
- 阴影留白占用窗口矩形，鼠标点在留白上不会穿透到下层窗口（视觉上是透明的）。

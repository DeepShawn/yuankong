# LanCmd 3.8.0

本地升级页直接上传手机 ZIP，并在升级成功后自动清理旧安装包。

- 「选择并上传 ZIP」打开手机文件选择器，分块上传到当前电脑的 upgrade 文件夹，显示进度并支持取消。同名文件另存，原包保留；上传完成后置顶显示，仍须确认「校验并安装」。
- 绑定打开页面时的电脑，换电脑或断线后停止上传；检查 Windows 文件名与 512 MiB 大小上限，失败／取消清理未完成文件。兼容旧接收端的列表数量限制。
- 只有新版已确认启动且升级报告完成后，才在后台校验并清理已用及旧版完整升级 ZIP，保留更高版本、损坏／普通 ZIP、失败包和回退备份。第一次从旧版升级也可清理；清理失败不会回滚或停止新版。
- 网卡、蓝牙适配器与对应设备增加「停用设备／启用设备」，与无线开关区分；要求现有管理员权限，限定设备类别并检查真实状态。相关连接可能中断，手机会查询原电脑任务结果。

沿用 miuix 主题和原签名，双端 **3.8.0**，安卓 versionCode **51**。本地升级只上传用户选择的文件，不从 GitHub 自动下载；Windows 不新增应用弹窗，系统必需权限与安全验证保留。

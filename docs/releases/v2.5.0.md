LanCmd 2.5.0 新增隐藏系统占位文件，以及文件管理中的 U盘连接控制。请同时更新安卓和 Windows 完整包。

- 文件管理 → 新建 →「隐藏系统占位文件 · 0–500 GB」：输入新文件路径和大小，0 表示空文件，支持精确到字节的小数 GB（1 GB = 1,000,000,000 字节）。实际逐块写入零数据，不使用稀疏文件或有效数据长度捷径；关闭文件压缩并检查实际分配空间后才报告完成。仅支持本地磁盘和 U盘中的普通目录，不覆盖同名文件，不通过链接或重解析点创建。FAT/FAT32 超过单文件限制时直接报错。
- 文件带 Windows 隐藏与系统属性，资源管理器默认不显示；开启显示受保护的操作系统文件后仍可查看。安卓文件管理始终列出，显示隐藏/系统标签，可使用原有删除操作释放空间。不会更改目录权限、系统显示设置或安装文件过滤驱动。
- 创建任务显示已写入和实际分配大小，支持取消。同一接收端一次创建一个占位文件；创建前和写入时检查剩余空间，至少保留 1 GB 可用空间。500 GB 写入可能耗时较长。手机断线继续创建；取消、失败或接收端退出时清理未完成文件。Windows 使用删除待定的文件句柄，异常进程终止后也会关闭并删除未提交文件。完成后文件保留，任务列表在接收端重启后清空，可在目标目录继续管理文件。
- 文件管理 →「U盘弹出 / 断开」提供安全弹出、强制断开和恢复入口。安全弹出使用既有 Windows PnP 安全移除接口，设备忙时在安卓显示错误，不自动改为强制操作。按设备执行，同一设备的多个分区一起断开。
- 强制断开需安卓单独确认，通过临时禁用所选 USB 磁盘节点中断访问，可能丢失未保存数据、损坏文件或文件系统。它不保证切断 USB 物理供电，驱动不支持时会失败。仅操作 USB 磁盘，不禁用控制器、集线器或其他设备；启动、系统和分页磁盘受到保护，接收端或恢复记录所在 USB 设备也拒绝断开。断开前先取消并等待相关占位任务清理。
- 禁用前将恢复记录写入 `%APPDATA%\LanCmd\usb-disconnects.json`；设备管理页显示恢复入口，可重新启用 LanCmd 记录的设备。记录跨接收端重启保留；设备已被拔出时需重新插入，部分驱动需重启。设备启停使用已有管理员权限，不主动弹出 UAC，状态未确认时不报告成功。

新增自动检查覆盖大小边界、实际小文件分配与隐藏/系统属性、取消和进程终止清理、剩余空间变化、USB 目标校验和恢复记录，以及安卓确认与连接切换。CI 不会分配 500 GB，也不会断开真实 USB 设备；实体 U盘、文件系统和驱动仍需实机验证。

升级前停止旧接收端并替换完整目录，保留全部配置、`device-policy.json`、`app-locks.json`、`usb-disconnects.json` 及恢复备份。安卓沿用原发布签名。

# LanCmd 3.6.0

远程画面改用 Windows 原生触摸输入，保留手机触控圆点。

- 转发单指／多点触点帧，经微软官方 InitializeTouchInjection / InjectTouchInput 发送按下、移动、抬起与取消。默认触控不再调用鼠标移动，也不替换或恢复系统鼠标图案。
- 共享结束、断线、输入会话结束、父进程退出或心跳超时后释放触点；校验完整触点帧、坐标、生命周期及所有权。接口不可用时停止，不自动回退为鼠标。
- 锁定本机输入时，仅放行对应已授权注入帧的触摸兼容消息，处理 Windows 手势识别的延迟；鼠标兼容按钮移到「更多操作」，使用时会移动鼠标。
- 触控工作进程回执编号与手机请求编号分开，安装包逐条验证实际 RPC 对应关系。升级页区分显示版本与内部构建号，确认目标构建已启动后才显示完成。
- 保留现有 miuix 主题、文件搜索状态修复及本地 ZIP 升级，不增加在线下载更新。

**使用官方软件触控注入接口，不安装虚拟 HID 内核驱动。** Windows 仍管理实际鼠标被使用后的指针显示；不承诺全局永久隐藏或消除第三方自绘图形。

双端版本 **3.6.0**，安卓 versionCode **49**，沿用原签名。请同时更新完整 Windows 包、退出旧接收端并重新启动，以及覆盖安装新版安卓。原有发布标签和文件保留。

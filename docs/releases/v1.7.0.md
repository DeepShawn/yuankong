# LanCmd 1.7.0

Android 控制体验更新，建议同时更新 Android APK 与 Windows 完整包。

- **电脑音量**：主页和远程桌面增加主音量面板，支持滑块、±10、预设百分比、静音和刷新。调节 Windows 默认输出设备；音量与静音独立控制。
- **常用命令**：主页与远程终端提供网络、用户、系统、进程、磁盘等命令提示，适配 CMD / PowerShell。点选仅填入输入框，点击执行后才运行。
- **本机输入暂停**：在远程桌面触控页选择暂停 30 秒或手动解除（不限时长）。电脑显示可见提示，手机保留远程键鼠操作。电脑同时按 **A、R、T、E、X + Ctrl + Delete** 解除；键盘不支持七键同时按下时，使用 Windows **Ctrl+Alt+Del**。手机可以提前恢复，结束共享、连接关闭或心跳中断 12 秒自动恢复。此功能暂停普通桌面的键盘、鼠标和转换为鼠标事件的触摸，不禁用硬件，不保证拦截独立触屏驱动的原始触摸，也不影响 Windows 安全桌面。
- **虚拟键盘**：远程按键页和桌面键盘页新增字母、数字、F1–F12、导航、标点及 Ctrl / Alt / Shift / Win 修饰键。修饰键只作用于下一个键，发送完成后自动释放。
- **发送文件**：选择手机文件后，点选电脑磁盘和文件夹作为目标，再确认发送，不再要求手输目录。读取失败时禁用目录确认；连接切换后停止原上传，清理操作仍发往原连接。
- 修正远程按键页遗留的“本机确认 / 5 分钟授权”提示，与当前连接方式一致。

更新前先在电脑停止旧接收端，替换完整目录后启动。Android 沿用 1.4.10 起的发布签名，可覆盖安装。Windows 音量及本机暂停需要 1.7.0 接收端；旧端仍可使用原有屏幕和按键功能。

自动验证包括 Android 单元与 Robolectric 界面测试、原生 Windows 功能与输入恢复测试、签名 APK 构建及 Windows x64 打包。组合键回调、断线与定时恢复通过自动测试验证；真实手机、七键键盘兼容性、触屏驱动和实体音频设备仍需设备实测。

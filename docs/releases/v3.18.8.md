# LanCmd 3.18.8

接入本机已安装的 **AdGuard Home Windows 服务**，并增加安卓独立 HTTPS 管理页入口。

- 电脑首次右键以管理员身份运行 `AdGuardSetup.cmd`，核对程序与服务配置后输入 `ENABLE`。后续 `start.bat` 在接收端新启动、已经运行及更新重启时按已确认的设置请求启动服务，不新增弹窗或通知。
- 未启用时不操作服务；已运行不重复启动；用户暂停／正在停止时不自动恢复。程序或服务命令变化需本机重新确认，权限不足不自动提权。
- 本机设置中保留运行状态、取消联动与停止入口；不隐藏或改名服务，不更改 Windows 服务启动类型。
- 安卓“网络与蓝牙 → AdGuard Home 网站守护”填写 HTTPS 管理地址，手机浏览器直接登录其管理页。只按电脑保存不含凭据的地址，拒绝 HTTP、嵌入密码和查询参数；不通过 LanCmd 转发管理凭据或访问记录。
- 启动联动不会安装／下载 AdGuard Home，不自动改 DNS、ICS、防火墙，也不开启访问记录。服务与手机 DNS、HTTPS 需要先在本机配置；软件本体不包含在安装包中。

查询记录、设备分组和网站／服务封禁由 AdGuard Home 管理页提供。只有实际使用该 DNS 的查询才受影响；热点 ICS 监听冲突和代理可能影响服务启动或设备区分。DNS 查询不能等同于网页访问或具体应用使用。详见 [配置与限制](../adguard-home.md)。

双端版本 3.18.8，Android versionCode 70，沿用原签名及 miuix／KernelSU 样式。原有 hosts 本机确认工具保留。本次没有加入远控流量监听、解密或静默访问记录接口。

发布文件：`LanCmd-3.18.8.apk`、`LanCmd-Windows-3.18.8.zip`、`SHA256SUMS-3.18.8.txt`。

# LanCmd 3.4.1

恢复文件夹改名的可达入口：每个文件或文件夹右侧都有操作按钮，也支持长按打开菜单。点击文件夹名称仍然进入目录；在「传输与整理 → 重命名」修改名称，成功后在顶部显示结果并刷新目录。

此次布局把空间优先留给画面、操作栏和内容列表。选择按钮与下拉选择更紧凑，同时保留至少 48 dp 的触控区域；收紧页头、说明文字、状态条和卡片留白。文件管理的磁盘信息、次要工具，搜索的筛选与索引设置、进程排序等按需展开。文件搜索与进程列表独立滚动，主要操作始终可达；长批量结果也有自己的滚动区，避免挤掉列表。

远程桌面、摄像头预览和手势板共享可用工作区：竖屏拖动中间分隔条可以分别增大画面或操作栏，横屏并排显示。操作栏自身可滚动。全屏仍保持画面比例，共享、输入和返回交接逻辑保留。文本编辑区改为填满剩余空间。

主题色从 6 种扩充为 12 种，新增青蓝、靛蓝、橙色、翡翠、珊瑚、雾蓝。保留四种深色背景，并添加「瓷白」「暖纸」亮色背景；亮色下使用相应深色强调色，适配正文、按钮、输入框、状态颜色、原生弹窗和系统栏。

新增可选择的「KernelSU 参考风格」，参考其清晰页头、分组列表、状态卡和底部导航重新组织公共外观；继续使用 Compose + miuix，并保留「miuix 经典风格」。两种风格都支持全部 12 色与深浅背景，在「外观主题 → 界面风格」切换。

远程桌面操作栏默认扩大至可用工作区的 52%，展开键盘时进一步增大；常用鼠标按钮、音量与本机输入控制优先显示，附加工具按需展开。横竖屏都能拖动分隔条调节画面与操作区。

修复文件和进程多选的即时显示：每项都有勾选框与选中背景，反选、同数量替换及取消立即更新。重命名和新建文件的输入窗口支持输入法，重命名时自动弹键盘并全选原名称。

手机画面保留圆形触控标记。配合 Windows 3.4.1 时，在可见远程桌面的触控模式临时隐藏电脑系统鼠标指针，关闭触控、离开页面或结束共享时恢复；接收端退出或失去心跳由独立进程恢复，不改注册表和指针文件。该功能没有新增 Windows 弹窗。旧 Windows 端可继续使用其余功能，但隐藏电脑指针需要完整更新 Windows 包。

Android versionCode 41，沿用既有签名。可把完整 3.4.1 ZIP 放进 `upgrade` 后从手机执行本地升级；不增加在线下载更新。

新增文件夹改名、长按与目录导航回归，以及工作区比例和紧凑按钮触控尺寸检查；亮色主题检查所有主题色的文字与背景对比度。界面预览由测试环境生成，真实设备显示仍以安装后的效果为准。

修复占位任务期间文件管理空白与等待：磁盘容量并行读取并设等待预算，不再同步探测所有盘；慢盘目录读取最多等待 3 秒，同目录重试复用原读取，避免线程堆积。已知目录优先加载，容量不可用时仍可操作其他目录；大目录排序移到安卓后台线程。保留原有稳定/快速分配速度策略、500 GB 上限、1 GB 余量、取消及清理约束。

修复应用冻结期间安卓长时间无结果：新增可查询的冻结/解冻后台任务；应用列表后台单次扫描和缓存返回，冻结结果不再触发同步全量扫描。应用中心增加「关闭」，安卓确认数据丢失风险后按进程创建时间核验并结束所选 EXE 进程，跳过关键进程与接收端自身，逐项报告失败。此处「关闭」会结束进程，不等待电脑端保存确认。上述响应改进需要完整更新 Windows 3.4.1 ZIP。

完整验证清单见 [v3.4.1-checklist.md](v3.4.1-checklist.md)。

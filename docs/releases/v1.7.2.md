LanCmd 1.7.2 取消本机键鼠暂停的定时恢复。

- 安卓删除「暂停 30 秒」选项和倒计时显示，只提供手动解除模式。
- Windows 移除暂停总时长和到期恢复逻辑。请求默认手动模式；旧客户端发送非零 `seconds` 时返回错误，不进入定时暂停。
- 连接正常时持续暂停，直到手机点击「恢复本机键鼠」或本机同时按 **A + R + T + E + X + Ctrl + Delete**。保留 **Ctrl+Alt+Del** 兼容入口。
- 退出共享、连接关闭或会话心跳中断 12 秒仍会恢复输入，避免连接中断后无法操作电脑。Windows 不创建暂停提示窗口。

请两端一起更新。电脑先停止旧接收端，再替换 Windows 1.7.2 完整目录并启动。安卓沿用原签名，可覆盖安装现有版本。

自动验证包括手动模式默认值、拒绝旧版定时请求、安卓只提供手动选项、快捷键与连接结束恢复，以及 Windows 暂停期间没有提示窗口。实体键盘兼容性和独立触屏驱动仍需设备实测。

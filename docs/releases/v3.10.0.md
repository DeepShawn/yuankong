# LanCmd 3.10.0

热点关闭后定时开启，同时修复新版 UI 的虚拟键盘底部裁切。

- 「网络与蓝牙 → 热点 → 热点定时开启」填写 1–86400 秒并确认，Windows 确认热点关闭后计时，到时独立开启；手机断线、退出页面或管理会话过期仍执行。安卓只读取电脑剩余时间，支持取消并查看最终结果。
- 与其他网络修改串行，关闭未确认不开始计时，开启失败不自动重试。手动开启、关闭、重启或修改热点配置会取消旧定时；取消不改变热点当前开关。
- 电脑和 Windows 接收端须保持运行；停止／重启接收端会结束本次定时。有待执行计划时先取消再升级接收端。
- 修复独立键盘和远程桌面键盘都被固定 300 dp 容器裁切的问题：现在按完整内容高度显示，外层操作区可滚动访问底部退格、回车、方向键和删除键。Delete 标注为「删除」，保留 Win／Ctrl／Alt／Shift 与各分区。

请同时更新安卓和完整 Windows 包并重启接收端。沿用网络管理密码和管理员验证、miuix 风格／主题及原签名。双端 **3.10.0**，安卓 versionCode **54**。Windows 不新增应用弹窗，必需的系统权限及安全验证保留；定时逻辑和原生接口测试不等同于已在用户无线硬件上实测。

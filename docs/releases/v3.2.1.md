LanCmd 3.2.1 修复子页面返回交接与 HID 触屏识别。

- 当子页关闭、父页仍存在时，给内部返回最多 5 秒的交接时间，避免较慢设备超过原 700 毫秒后误结束远程桌面或摄像头共享。父页恢复后继续原会话；真正退到后台仍使用原后台判断。交接未恢复时也会结束共享并恢复输入。
- HID 触屏改用 Windows SetupAPI 原生枚举，只读取已连接 HIDClass 的硬件 ID 和兼容 ID，不再启动 PowerShell，避免截图中的逐项查询超时和整段脚本错误。只匹配标准触屏标识，不禁用键盘、鼠标或父控制器。
- 继续核验实际禁用状态，保留独立恢复进程、断线恢复和原已禁用设备的状态。无法识别标准触屏或属性读取失败时，不降级为仅锁键鼠；驱动等待超时显示简明失败信息。

Android versionCode 37，沿用发布签名，可覆盖安装。Windows 请先停止旧接收端，再替换完整包；只更新手机不会更新 HID 识别代码。保留 `%APPDATA%\LanCmd` 下配置和恢复记录。

实体触屏驱动仍需实机验证；本版本不保证所有厂商触控设备都能暂停。直接关闭共享页面仍会结束共享。

# LanCmd 3.18.7

Windows 包增加 **本机确认的 hosts 网站限制工具** `WebsiteRules.cmd`，需在电脑右键以管理员身份运行。输入完整域名列表后，工具显示差异并要求输入 `APPLY` 确认，再修改这台电脑的系统 hosts 文件。撤销功能只移除工具自己的规则区。

- 批量添加明确域名，同时生成 IPv4 和 IPv6 条目。子域名需单独列出；不接受通配符、网址路径、端口或 IP。
- 保留其他 hosts 条目、注释和原有字节；与已有映射冲突时不覆盖。
- 修改前保留备份，写入前复核文件修订，替换后核对结果；Windows 使用 `ReplaceFileW` 保留原文件 DACL，不自动提权或解除只读属性。
- hosts 规则无需后台进程，关闭接收端或重启电脑后仍保留，无需加入 `start.bat`，没有新增启动通知。
- 仅作用于本机采用系统 DNS 解析的请求。加密 DNS、VPN、代理、直接 IP、缓存或已有连接可能绕过或延后限制。

此版本**没有加入 Android 远程 hosts 改写、热点访问记录、流量监听或应用使用分析**。hosts 本身不提供这些能力。工具仅提供本机确认后的域名限制，不增加远控接口、端口或后台服务。其他现有功能保持原有行为。

操作与恢复说明见 [本机网站限制](../local-website-rules.md)。备份位于 `%LOCALAPPDATA%\LocalWebsiteRules\backups`，不会自动删除；撤销时保留其他程序后来修改的内容。

双端版本号 3.18.7，Android versionCode 69，安卓界面及功能未改，沿用原签名。

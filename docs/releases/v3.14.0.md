# LanCmd 3.14.0

- 新增「局域网电脑与历史」：首页「电脑」、更多菜单及工具库均可进入，断线时也可查看；手动刷新列出运行接收端并响应发现协议的电脑，展示原机名、地址、标识和发现时间。本次未发现不等于关机。
- 电脑备注名最多 40 字，留空恢复原名，首页同时保留原机名及地址。按接收端标识／端口保存，同一电脑换 IP 仍保留；旧版无标识时按地址区分。修改的是手机备注，不改 Windows 系统机名。
- 连接历史持久保存在手机，记录成功连接与结束时间，可搜索、逐条删除或清空。保留最近 200 条和最多 100 台电脑；异常退出可能没有结束时间。上次连接只迁移为已保存电脑，不伪造历史；不保存命令内容与凭据。
- 浏览、刷新、改备注和清理历史不切换或中断当前连接；清理保留配对凭据。沿用原连接与授权流程，未增加新控制入口。

安卓 versionCode 58，沿用原 APK 签名、miuix／KernelSU 风格。Windows 仅同步版本号；完整替换 Windows 包后重启。

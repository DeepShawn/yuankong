# LanCmd 3.7.0

新增「网络与蓝牙」管理页，修复双击与长按触控帧，沿用现有 miuix 主题和风格选择。

- **触控修复**：按住期间持续发送静止 UPDATE 帧，抬起前保证完整 UPDATE，再发送 UP；连续双击和复用触点编号保持独立生命周期。维持触点不会延长断线 watchdog，保留手机触控圆点与原生触控路径。
- **热点**：开启、关闭、重启，修改名称、8–63 位 ASCII 密码和支持的频段，查看客户端 MAC／主机名。
- **Wi-Fi**：Windows WLAN 原生扫描、信号和已保存配置，连接、更新连接密码、断开与忘记；不回传旧密码。企业认证使用电脑上已配置的配置文件。
- **蓝牙**：无线开关、搜索可发现设备、配对／取消配对及真实连接状态。手机确认匹配码或输入 PIN，未确认会超时取消；音频、HID 等实际连接由相应 Windows 服务建立。
- **网卡**：查看 IP、网关、DNS、MAC 和链路，启用／停用、自动或自定义 DNS、DHCP 续租。
- 操作在 Windows 后台执行，返回任务编号后再改变网络；手机重连只查询原电脑任务。请求去重，密码和 PIN 不写入任务结果或页面恢复数据。
- 可能断开手机的操作在手机确认。应用不新增 Windows 弹窗；系统必需的权限及安全验证保留，权限不足时显示实际错误。

Windows 公共热点接口不支持通用的逐个踢出客户端，提供更换密码及关闭／重启热点。无线功能取决于电脑网卡、驱动、WLAN 服务、可共享网络及系统权限；不安装额外驱动，不自动修改全局防火墙。

双端 **3.7.0**，安卓 versionCode **50**，沿用原签名。请覆盖安装安卓，完整替换 Windows 接收端并退出旧进程后重新启动；也可将完整 ZIP 放入现有 upgrade 文件夹进行本地升级。

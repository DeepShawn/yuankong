LanCmd 2.2.0 新增电脑录音、录屏、摄像头视频录制，以及空白手势板和延迟回放。请同时更新安卓与 Windows 完整包。

- 首页「更多 → 录音 / 录屏 / 摄像头录制」选择模式、设备和时长；远程桌面及摄像头预览页也可进入录制。
- 环境录音使用电脑麦克风，保存为 WAV；屏幕和摄像头保存为 H.264 MP4，可同时录制麦克风声音（AAC）。这里的声音是麦克风采集，不含电脑内部系统音频。
- 视频保持画面比例，最长边受 1280×720 边界限制，约 12 帧/秒；录屏包含整个虚拟桌面及鼠标指针。实际帧率取决于电脑和驱动性能。
- 手动开始、停止，支持 1–3600 秒时长（默认 300 秒）；手机断线或离开页面后继续到设定时长，退出接收端会停止采集并尝试封装文件。单文件约 1 GB 上限，磁盘空间不足时提前停止。
- 文件保存在电脑 `%APPDATA%\LanCmd\recordings`，安卓可查看状态、下载到选择的位置、交给手机播放器播放或删除；可通过安卓文件管理访问录制目录。停止后请等待「已完成」再下载。驱动卡住或异常终止的文件可能不完整。
- 首页「更多 → 手势记录 / 延迟播放」及远程桌面进入空白手势板。在板上记录鼠标移动、左键点击和拖动；按相对坐标映射整个电脑桌面，按原始时间间隔回放。录制阶段不会操作电脑。
- 手势单次最长 5 分钟、6000 个事件，手机最多保存 20 条；支持 0–86400 秒后播放、取消。回放期间独占远程鼠标；离开手势页或连接结束会取消并释放按键。不是多指触屏注入或键盘宏。
- LanCmd 新操作不新增 Windows 应用弹窗、通知或控制台；系统麦克风/摄像头隐私权限、使用状态指示和硬件指示灯保持有效。不自动更改隐私权限；权限不足、设备占用、缺少媒体组件或驱动失败会返回安卓错误。

Windows 包新增 `LanCmdRecord.exe`，使用系统 Media Foundation、GDI 和 WaveIn，不需要安装 FFmpeg。Windows N 版需系统媒体功能包。升级前停止旧接收端、替换完整目录，保留原配置与 `device-policy.json`；安卓继续沿用原发布签名。

自动检查涵盖真实 Windows MP4 音视频编码/解码、WAV、录制状态和归属、手势时序与取消、安卓触摸与页面渲染；实体麦克风、摄像头及驱动兼容性仍需实机验证。

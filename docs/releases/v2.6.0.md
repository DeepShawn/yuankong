LanCmd 2.6.0 改进共享页面返回、功能分类、按钮附近的结果提示，以及 Windows 本机输入暂停。请同时更新安卓与 Windows 完整包。

- 已开始的远程桌面、摄像头预览和键盘会话，在进入应用内子页面时保留原连接。画面页隐藏期间暂停取帧、保持会话，返回继续显示；不会自动连接其他电脑。真正离开应用会结束共享并恢复输入，短暂的页面切换留有交接时间；关闭共享页、手动停止、连接变化和断线仍会结束会话。
- 摄像头预览进入录制页时等待在途采集结束，返回时若仍在录制则保留会话并提示等待，录制结束后继续预览，避免两者抢占摄像头。保存到外部应用等真正离开 LanCmd 的场景仍按后台规则停止共享。
- 操作结果紧邻触发按钮或同一按钮组显示，长结果可点开查看。不同异步操作保留各自结果，刷新操作组时重新挂接未完成操作的结果；不要求回到页面顶部寻找。
- 首页分为「共享与控制」「文件与设备」「系统与应用」「录制与自动化」，屏幕入口统一到远程桌面，进程管理统一到任务管理器。录制、手势与隐私设备使用分类入口；更多菜单分为连接管理、应用设置、电脑电源。
- 本机输入暂停始终检查 HID 触屏，不再仅因桌面触控标志为零而跳过外接设备。匹配标准触屏的硬件 ID 和兼容 ID，不扩大到触控板、键盘或整个 HID 控制器。Windows 报告触控能力却无法识别设备时返回错误。
- 禁用后核实设备已处于禁用状态，恢复后核实已启用；跟踪本次禁用的设备，保留原已禁用设备。状态被外部更改或恢复进程失败时解除键鼠锁并显示原因，仍在恢复时拒绝再次锁定。安卓显示实际识别和禁用数量，未检测到标准 HID 触屏时不声称触控已锁定。
- 远程输入改在请求线程发送，避免长文字占用低级键鼠钩子的消息处理线程而使 Windows 移除钩子。断线心跳、原本的本机解锁组合键、Ctrl+Alt+Del 和独立触屏恢复进程保持有效，不增加 Windows 应用确认弹窗。

自动检查覆盖子页面往返、后台退出、摄像头录制占用、异步结果位置、分类导航、HID 检查和恢复流程。CI 无法验证你的实体触屏和厂商驱动；自定义驱动或绕过普通键鼠消息的应用仍可能不受标准钩子限制，状态以接收端核验结果为准。

升级前停止旧接收端、替换完整目录，保留全部配置和恢复记录。安卓继续使用原发布签名。

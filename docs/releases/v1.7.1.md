LanCmd 1.7.1 调整本机键鼠暂停的提示方式。

- 暂停本机键鼠时不再创建 Windows 桌面横幅。安卓端显示暂停状态和解除方法。
- 保留 **A + R + T + E + X + Ctrl + Delete** 物理组合键解除、**Ctrl+Alt+Del** 兼容入口、手机端提前恢复、30 秒定时模式及手动解除模式。退出共享或心跳中断 12 秒自动恢复。
- 修正安卓预览页面遗留的本机确认、共享提示和 5 分钟限制文案。
- Windows 的正常 UAC、本地启动面板操作和主动“发送消息”的消息框保留。

电脑先停止旧接收端，再完整替换 Windows 1.7.1 目录并启动。安卓 1.7.1 沿用原签名，可覆盖安装 1.4.10 至 1.7.0 中使用现有签名的版本。

自动验证包括 Windows 原生输入钩子安装、工作线程没有可见提示窗口、组合键回调、消息循环、定时/手动/断线恢复，以及 Android 单元和界面回归。实体键盘七键兼容性与独立触屏驱动仍需设备实测。

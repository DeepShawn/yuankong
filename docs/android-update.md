# 安卓应用内更新

LanCmd 安卓端自带更新检查，不需要电脑端参与，也不需要任何第三方更新服务。

## 从哪里检查

- 应用启动时自动检查：距离上次成功检查超过 24 小时才会请求一次。
- 手动检查：「更多 → 检查更新」，或「关于 → 检查更新」。
- 数据来源只有一个公开接口：`https://api.github.com/repos/DeepShawn/yuankong/releases/latest`。
  只读取版本号、更新说明和 `.apk` 资产的下载地址，不上报设备信息、连接记录或使用统计。

## 下载与安装流程

1. 发现新版本后首页出现「应用更新」玻璃卡片，显示版本、安装包大小和更新说明入口。
2. 点「下载并安装」后下载到应用私有目录 `cache/updates/`，卡片内显示进度，可随时取消；退出页面不会中断下载。
3. 下载完成后校验：
   - 包名必须是 `com.aicode.lancmd`；
   - 版本号必须与 Release 标签一致且高于当前版本；
   - 签名证书 SHA-256 必须是官方发布证书 `0e3f1973d35093280b1bf018af86bafb957a1048b529cfe1954638f10f4a1fed`。
   任一项不通过都会删除文件并提示原因，不会打开安装器。
4. 校验通过后通过 `FileProvider` 把 APK 交给系统安装器，覆盖安装并保留数据；Android 会显示系统安装确认，应用不做静默安装。
5. 首次使用需要允许 LanCmd「安装未知应用」；应用会自动跳转到授权页，授权后返回会自动继续。

## 已知限制

- 需要手机能访问 GitHub（部分网络环境需要代理/VPN）。
- GitHub Releases API 未认证请求有频率限制（每小时 60 次），应用最多每 24 小时自动请求一次，正常使用不会触发。
- 只支持 x.y.z 形式的正式版本标签；预发布版本、草稿和 `-touch.N` 类标签不会被自动更新选中。
- 下载只在应用运行期间进行（前台或后台均可，退出应用会中断），不支持断点续传。

## 相关代码

- `UpdateChecker.kt`：版本比较、Release 解析、下载、签名校验、安装意图。
- `MainActivity.kt`：自动/手动检查、更新卡片、下载进度、安装权限跳转。
- `UpdateCheckerTest.kt`：版本比较、Release 解析、下载与拒绝伪造包的测试。

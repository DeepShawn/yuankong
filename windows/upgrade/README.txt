可在安卓「Windows 本地升级」页直接选择手机 ZIP 上传到此文件夹，上传完成后选择「校验并安装」。
将新版本完整的 LanCmd-Windows-x.y.z.zip 手动放在此文件夹。
安卓端进入「系统 → 本地升级」，刷新、选择 ZIP 并确认。
只读取本机文件，不访问 GitHub 或自动下载。请使用高于当前版本、带 release-manifest.json 的完整 amd64 便携包。
升级会暂时断开连接，成功后自动重新连接；失败时尝试恢复原文件并重启旧接收端。
先停止录制、传输、脚本及延迟任务，冻结应用会先尝试解冻。
暂存、备份和启动日志位于安装目录的 .upgrade\run-...，与安装目录同盘；状态保存在 %APPDATA%\LanCmd\upgrade。升级包由用户自行确认来源；内置 SHA256 清单用于检查内容完整性，不是数字签名。

3.4.2 起，校验通过后断开连接并释放共享输入；等待旧接收端退出，再解压、替换文件、运行 start.bat --upgrade。更新用 CMD 不显示窗口且执行后自动退出。手机自动等待原电脑重连并读取对应更新任务的结果。

3.8.0 起，新版接收端确认启动且升级完成后，自动校验并清理本目录内已用及旧版完整升级 ZIP。更高版本、损坏／普通 ZIP、失败升级和 .upgrade 回退备份保留。清理不会停止正常运行的新版。

LanCmd Windows 接收端 v3.7.0
========================================

3.4.1：安卓恢复文件夹操作菜单与长按入口；选择控件更紧凑，画面与操作栏可拖动调节比例，列表独立滚动。
外观主题扩充至12种主题色、4种深色与2种亮色背景。Windows服务功能不变，同步版本号；已有3.4.0可继续配合新版安卓使用。

3.4.0：安卓工作区全面重新排版，系统分类新增应用中心、桌面背景与本地升级。
应用中心自动识别桌面 EXE，可选择应用锁目标、暂停与恢复正在运行的进程。关键进程、Windows 目录和接收端自身受保护。
将新版本完整 Windows ZIP 手动放到解压目录的 upgrade 文件夹；安卓「系统 → 本地升级」校验并安装，只读取本机文件，不访问 GitHub 下载。
升级会短暂断开连接，保留回退备份；已有录制、传输、脚本、文件与延迟命令任务须先完成或取消。
任务视图的虚拟桌面共用当前画面和输入，本版本没有独立后台桌面控制，也不会自动切走主屏。

3.2.2：U盘占位文件继续优先快速分配真实空间，按磁盘响应自适应批次（1–256 MiB），逐段设置文件长度。
新增稳定／快速模式，默认稳定：稳定模式批次最大32 MiB并适度让行，回退实际写入约64 MiB/s上限、每16 MiB刷新；快速模式批次最大256 MiB，回退写入不限速、每64 MiB刷新。预分配本身不按文件逻辑大小强制等待。
磁盘检查在后台执行，任务查询与取消不等待检查或提交持有全局任务锁；后台I/O优先级优先让行前台操作。
取消后会先显示取消中，当前磁盘调用返回、清理完毕才显示已取消。驱动自身若长时间不响应，不能保证立即取消，请等待恢复；不会强行断开U盘。

3.2.1：HID 触屏识别使用原生 SetupAPI 读取硬件与兼容 ID，不再启动 PowerShell。
继续校验实际禁用状态，并由独立进程在断线时恢复。标准触屏识别或属性读取失败时不降级为仅锁键鼠。
此修复必须停止旧 Windows 接收端并替换完整包；安卓同时改进子页返回的共享交接。

解压整个文件夹后双击 Start.exe，点击「启动接收端」。
目标电脑不需要安装 Python。支持 Windows 10/11 x64。
升级前先运行 LanCmdCtl.exe --stop，替换完整目录后重新启动。

一、手机连接
----------------------------------------
手机和电脑连接同一 Wi-Fi，或让手机连接电脑的移动热点。
打开 Android 3.7.0，会自动发现电脑；也可手动输入 Start.exe 中的 IP。
手机统一显示为「LanCmd 手机」，不再发送手机机名或型号；原配对 ID 保留。

二、功能
----------------------------------------
远程桌面：手机首页点击新卡片或「屏幕」，再点「开始共享」。
在画面上轻点单击、双击、长按右键、单指拖动、双指滚动；黑边不触发点击。
下方可切换触控、键盘和命令终端。横屏时控制区在画面右侧，也可全屏查看。
画面、键鼠与终端使用独立连接，长命令不阻塞触控；离开页面时结束共享。
摄像头：点击「开始查看」，选择摄像头，按帧预览，无录音。
按键：向当前前台应用发送组合键或文字。
消息：发送后会在电脑桌面显示，可在电脑关闭消息框。
存储：查看磁盘容量、导航与搜索目录、上传下载、重命名、新建和删除。
手机保存画面或下载文件时，可通过系统文件选择器选择保存位置。

当前接收端沿用 1.5.0 行为：完成握手即可使用功能，不校验 token，
没有本机确认窗口或共享时长上限。手机退出页面或断开连接时释放会话。
本机可通过 Start.exe 或 LanCmdCtl.exe --stop 停止接收服务。

三、后台运行和管理
----------------------------------------
Start.exe              启动、停止、开机自启、修复防火墙、查看本机地址
LanCmdAgent.exe        后台启动接收服务，无主窗口
LanCmdCtl.exe --status 查看运行状态
LanCmdCtl.exe --stop   停止服务
LanCmdCtl.exe --install-autostart    开机自启
LanCmdCtl.exe --uninstall-autostart  取消自启
--auto-accept / --no-auto-accept     旧版兼容参数，已忽略，不改变连接行为
LanCmdCtl.exe --reset-pairing        清除配对

配置、日志和配对记录在 %APPDATA%\LanCmd。
移动目录后，需要重新设置开机自启。

四、文件说明
----------------------------------------
LanCmdAgent.exe / LanCmdCtl.exe / Start.exe   启动和管理工具
LanCmdCapture.exe     屏幕与摄像头采集辅助程序，不要删
lan_command_agent.py  接收端逻辑，不要删
remote_features.py   会话、消息与输入逻辑，不要删
python\              自带运行时，不要删

五、连接与设备排错
----------------------------------------
1. Start.exe 确认接收端正在运行。
2. 确认手机和电脑在同一局域网，没有 AP 隔离。
3. Start.exe 点「修复防火墙」，在 UAC 中允许；会放行 TCP 47823 / UDP 47824。
   也可管理员执行 LanCmdCtl.exe --fix-firewall。
4. 热点连接通常可手动填 192.168.137.1；手机需保持该 Wi-Fi，避免自动切回移动数据。
5. VPN 需允许局域网直连。
6. 摄像头失败：检查设备连接、是否被占用，以及 Windows 隐私设置中的桌面应用摄像头权限。
   Windows N 可能需要安装 Media Feature Pack。
7. 按键控制要求电脑已解锁，不能控制 UAC 安全桌面或权限更高的窗口。
8. 缺少新命令或采集组件：停止旧版，完整更新 Windows 1.9.0 与 Android 1.9.0。

六、1.5.1 修复
----------------------------------------
修复启动器命令行前导空格和 Windows 参数转义，避免 Python 启动失败。
修复不覆盖上传时的同名文件竞争覆盖；非法 base64 和超量分块会被拒绝，
提交失败会清理临时文件及会话。Android 1.9.0 可覆盖安装 1.4.10 和 1.5.0。

协议使用局域网明文传输，适用于自己授权管理的电脑与可信网络。

七、1.6.1 进程与权限修复
----------------------------------------
手机进程页的全选不会再关闭列表；支持取消全选，筛选或刷新时清理失效选择。
电脑 Start.exe 增加「管理员启动 / 重启」。点击并允许 Windows UAC 后，
才会停止普通权限接收端并以管理员身份启动；取消授权则保留旧连接。
面板与手机进程页显示接收端的实际权限。管理员并非 SYSTEM 或系统最高权限，
部分受保护系统进程仍会拒绝操作。普通开机自启仍为标准权限，需要时重新授权。

八、1.7.0 安卓控制更新
主页/远程桌面可调节默认输出设备主音量与静音；常用命令先填入再执行。
新增虚拟键盘，修饰键只影响下一个键；发送文件改为选择电脑磁盘和文件夹。
远程桌面触控页可暂停本机键鼠，仅支持手动解除，不按时长恢复，状态与解除说明显示在安卓端。
本机解除：同时按 A R T E X + Ctrl + Delete；七键冲突时使用 Ctrl+Alt+Del。
退出共享、连接关闭或会话心跳中断 12 秒自动恢复，不保存暂停状态。
旧版仅暂停普通桌面键鼠；1.9.0 另含标准 HID 触屏临时暂停，见第十三节。
完整包新增 system_controls.py、input_guard.py，更新时一起替换。

九、1.7.1 提示调整

十、1.7.2 手动解除
取消暂停时长和定时恢复，连接正常时持续暂停，直到手机或本机手动解除。
旧客户端的非零 seconds 请求会被拒绝，请一起更新安卓。
共享结束、连接关闭与 12 秒心跳中断恢复保留。

十一、1.8.0 U盘锁与移动设备管理
手机首页「U盘锁 / 设备」查看 USB 存储、移动硬盘和 USB MTP/PTP 手机。
U盘 / 可移动磁盘支持锁定、只读和解锁；MTP/PTP 设备支持锁定和解锁。
策略按设备类别应用，重启后保留；保存文件后重新插拔设备，必要时重启。
部分 USB 硬盘被 Windows 识别为固定磁盘，不一定受可移动磁盘策略限制。
解锁恢复 LanCmd 修改前的策略，不清除原有 Windows 限制；域策略可能覆盖。
恢复记录在原配置目录 device-policy.json，升级时保留。其他程序改变策略时拒绝覆盖。
修改和弹出需 Start.exe 管理员启动并允许系统 UAC；标准权限可查看。
设备忙则返回失败，不强制卸载；系统磁盘禁止弹出。
操作确认与结果只在安卓显示，Windows 不新增应用弹窗或控制台。
原有 Windows UAC、本地主动交互和主动发送消息保留。
完整包新增 device_management.py，不要遗漏。实际设备兼容性需实机验证。

十二、1.9.0 虚拟键盘界面
安卓虚拟键盘改为字母、符号、功能分区，按屏宽排列，固定显示修饰键和常用控制键。
组合键高亮且仅作用于下一键，支持清除；收起键盘或停止控制时复位。
符号页按 Windows 美式物理键位发送，其他布局可改用文字输入。
本次 Windows 仅更新版本资源，1.8.0 的接口和设备管理行为保持兼容。

十三、1.9.0 工作台
输入暂停包含标准 HID 触屏，需管理员权限；使用临时禁用与独立恢复进程。
恢复进程随接收端管道中断、丢失心跳或解除操作恢复本次禁用的触屏，不改变原禁用设备。
无法识别或禁用触屏时返回失败；驱动若拒绝恢复，请重新连接设备或重启 Windows。
手机桌面页新增运行程序窗口列表，可切换、最小化、正常关闭。
文件管理支持电脑打开应用、文件和文件夹，以及文本/图片/ZIP 目录预览。
ZIP 解压到新文件夹，不覆盖已有目标，限制 2000 项和 512 MB，拒绝越界和链接。
命令列表按顺序运行，每条在上一条结束后等待指定秒数；失败继续下一条。
手机断线仍执行，接收端退出不保留计划；取消只作用于尚未开始的命令。
全屏按像素等比显示，触控坐标与显示区域一致。
新模块 touch_guard.py、file_actions.py、desktop_apps.py、command_queue.py 需一并保留。

2.2.0 录制与手势
手机「更多」进入录制或手势板，远程桌面和摄像头页也提供录制入口。录制使用电脑设备，文件在 %APPDATA%\LanCmd\recordings，停止后等待封装完成再下载。麦克风/摄像头隐私权限和系统指示保持有效。录屏可含麦克风声音，不含系统内部音频。默认 300 秒，可设 1–3600 秒；手机断线继续，接收端退出会停止并尝试封装。异常终止的 MP4 可能不完整。
手势录制只在手机画板上记录，播放才操作电脑鼠标，支持左键点击/拖动和相对坐标，延迟 0–86400 秒；离开手势页或断线取消并释放按键。详细限制见 docs/releases/v2.2.0.md。
完整包必须包含 LanCmdRecord.exe、recordings.py 和 gestures.py；Windows N 需系统媒体功能包。

2.3.0 管理功能
文件管理可新建 TXT/BAT/VBS/CMD/PS1 等文本文件，并在线编辑（最多512KB），可选择编码与换行，支持手动/可选自动保存、手机草稿和修改冲突检查。BAT/CMD/VBS 可从菜单运行，隐藏宿主，输出在安卓查看；每次最长300秒，最多4个并行，可取消。VBS 先检查组件能否实际执行，不自动安装组件或修改脚本策略；批处理模式抑制交互提示，文字输出请使用 WScript.StdOut/StdErr。脚本自己打开应用的行为仍会执行，取消不能撤销已执行的操作。
首页新增任务管理器、注册表编辑器、浏览器和应用锁卡片；更多/设备管理/录制页可管理摄像头和麦克风设备。设备启停需管理员，影响所有应用，仍遵循系统隐私权限。
应用锁限制所选EXE的当前用户执行权限，不强退运行程序，不追踪替换后的新文件。请保留 %APPDATA%\LanCmd\app-locks.json 和 app-lock-backups 归档，解锁时恢复原权限。注册表值修改前会备份到 %APPDATA%\LanCmd\registry-backups，可在安卓选择恢复。系统目录和LanCmd自身受保护；外部权限和值变更会停止覆盖。
详细说明见源码 docs/releases/v2.3.0.md，升级时替换完整目录并保留原配置与全部策略/权限/注册表备份。

2.5.0 隐藏系统占位文件与 U盘连接
文件管理 → 新建 → 隐藏系统占位文件，指定完整路径与 0–500 GB（1 GB=10亿字节）。逐块写入普通文件，核实实际分配空间，至少保留 1 GB 空闲；不使用稀疏文件，不覆盖已有文件。创建过程中可取消，接收端退出或失败会删除未完成文件；手机断线继续。完成文件保留隐藏+系统属性，在安卓文件管理仍可看到并删除，Windows 开启显示受保护系统文件后也能看到。任务记录仅在本次接收端运行期间保留，重启后在目标目录管理完成文件。
文件管理 → U盘弹出 / 断开：安全弹出遇忙返回错误；强制断开通过临时禁用选中 USB 磁盘实现，可能丢失数据或损坏文件系统，并不保证切断供电。强制断开需安卓单独确认，禁用前保存 usb-disconnects.json，设备管理页可恢复。只操作 USB 磁盘，不禁用控制器或集线器，不操作系统/启动/分页磁盘；接收端和恢复记录所在 USB 设备也不允许断开。启停需管理员，驱动拒绝或状态未确认时在安卓报错，不自动弹出 UAC。升级请保留全部配置、app-locks.json、usb-disconnects.json 和恢复备份。

2.6.0 共享与输入暂停
安卓进入应用内子页面会保留原共享会话、暂停取帧，返回继续；离开应用或关闭共享页会结束，切换电脑后需重新开始。摄像头正在录制时预览等待录制结束。首页按共享控制、文件设备、系统应用、录制自动化分类，屏幕统一进入远程桌面，进程管理统一进入任务管理器。操作结果在触发按钮或操作组附近显示，可点开查看完整内容。
本机输入暂停始终枚举标准 HID 触屏，不再仅凭桌面触控标志跳过。核对真实禁用与恢复状态；识别不完整、驱动不支持或状态不确定会报错，不假报触控锁成功。识别数、本次禁用数及原已禁用数由接收端返回。发送长文字不再占用钩子线程。断线心跳恢复、本机解除键、独立触屏恢复进程继续保留；不禁用整个 HID 控制器，也不屏蔽 Ctrl+Alt+Del 或安全桌面。请两端同时升级，实体触屏仍需实机验证。

2.7.0 多选与 USB 兼容修复
- 安卓文件管理长按或选择“多选”，支持每批最多 100 项的复制、移动、删除和下载。
- 复制、移动只使用已有目标目录，不覆盖同名项目。失败项目继续报告，取消不能撤销已完成步骤。
- Windows 计时执行文件任务，离开页面不停止；重新进入“文件任务”查看或取消。
- 批量删除不可撤销；跨卷移动如无法清除源文件，会保留目标副本并报告。
- 文件与进程结果在页面顶部显示，展开可查看逐项详情，没有额外结果弹窗。
- “占位文件”按钮直达真实占用 0–500 GB 的任务页。隐藏/系统属性不会将其从 LanCmd 文件列表隐藏。
- USB 强制断开需要支持该动作的接收端。如提示“无效的设备管理操作”，先在 Start.exe 停止旧接收端，替换完整新版 Windows 包（全部 .py 文件也要更新），再重新启动、连接。不要仅覆盖安卓或 EXE。
- 强制断开通过禁用 USB 存储设备实现，可能仍供电；不是物理断电。建议优先安全弹出；在设备管理中恢复连接。

在当前窗口下方打开请求不激活，并在启动后最多30秒维护已确认的目标窗口层级；也识别被启动请求激活的复用窗口，按完整程序路径核实。主动切换、关闭或最小化原窗口后停止维护。同一窗口内标签页复用、Windows前台限制或更晚的应用激活仍可能不遵守；不隐藏应用，不拦截系统提示。
延迟按钮设置 0–86400 秒，作用于后续文件操作；Windows 操作由接收端计时，断线继续，接收端重启不保留。延迟计划可取消等待中的操作。手机传输/WPS 需手机保持连接及应用存活。修改日期采用手机本地时区，保留访问时间。

2.8.0 摄像头停用与界面菜单
新版停用摄像头先等待 LanCmd 当前取帧完成，关闭摄像头共享会话；相关录制请求停止并等待释放，期间阻止新录制。只处理 LanCmd 自己的采集，不终止其他应用。
设备管理常规接口若返回 0x17 等驱动否决，改用 Windows SetupAPI 的设备属性变更接口。仅操作选择的 Camera/Image/捕获音频端点，重新核验设备类别，不操作父控制器和扬声器；设置 DI_QUIETINSTALL，不新增安装器界面。系统安全与隐私提示保留。
驱动仍可拒绝操作，不能保证所有实体/虚拟摄像头都能禁用。仅在读回已停用时显示成功；若需要重启，安卓显示待重启，不自动重启电脑。重新启用同样验证状态。实体 SC06 等设备仍需实机检查。
安卓：首页分类切换，功能页右上角可搜索全部工具。文件菜单 → 编辑与属性 → 最后修改日期，支持日期和时间选择，按手机本地时区；文件操作延迟设置继续生效。结果在原设备卡片或页面顶部显示，不另弹结果窗口。

文件搜索（索引）
安卓首页文件与设备 → 文件搜索，先选择全部本地固定磁盘或一个文件夹建立索引。支持中文、文件名/完整路径、多关键词、双引号短语、* 和 ? 通配符、类型筛选、排序与分页。只扫描属性，不读取内容，不跟随链接和重解析点，无权限目录跳过。最多200万项、保留1GB空闲，首次扫描可能较久。索引保存在 AppData/LanCmd/file-search/files.sqlite，取消或失败保留旧索引，手机断线继续。文件变动后请手动更新；不保证实时感知磁盘变化。搜索结果可在文件管理定位高亮，继续打开或编辑；原件发生变化时版本校验可能要求刷新索引。
Windows ZIP 已保留 SQLite 运行库，更新时仍须替换完整包。首页“电脑信息”移入右上角连接管理菜单。

2.9.0 快速占位与 USB 0x17 兼容
占位文件优先通过 Windows FileAllocationInfo 分段预分配普通文件真实磁盘空间，再设置文件长度并核实实际分配；不设为稀疏文件、不调用 SetFileValidData，未初始化数据由 Windows 保证读取为零。保持0–500GB、隐藏+系统属性及至少1GB空闲。明确不支持的文件系统回退逐块写入，先清理此前的预留再重新创建。速度受文件系统、碎片与磁盘影响，不承诺500GB瞬间完成；分段之间支持取消，当前系统调用返回后清理。
USB 0x17：先尝试原常规接口，再尝试仅所选 USB DiskDrive 的设备属性兼容接口。仍不禁用父控制器/集线器，不自动提权/重启。操作前持久化恢复标记，驱动要求重启或状态未确认时不假报断开，记录保留；设备仍显示启用时也能在恢复连接中撤销待生效的停用配置。兼容路径可能保留停用设置，请使用恢复连接，不要只删除 usb-disconnects.json。
请先停止 Windows 旧接收端，替换完整2.9.0包后启动；截图中的2.6.0进程不会因只更新手机而获得修复。具体 ASolid USB 等驱动仍需实机确认，若两种接口都拒绝，安卓保留错误与恢复记录。

3.4.1 远程触控指针：安卓进入可见远程桌面触控模式时，临时隐藏 Windows 系统鼠标指针；关闭触控、离开页面或结束共享后恢复。独立心跳恢复进程在接收端退出、失联后恢复，不更改注册表或指针文件，不增加 Windows 弹窗。

3.4.1 响应修复：占位期间的磁盘容量读取按盘隔离；目录等待有上限且同目录重试复用，慢 U 盘不会占满整条请求连接。应用列表使用后台缓存；冻结、解冻和关闭应用使用可查询后台任务。应用关闭会结束所选 EXE 的当前进程，安卓会先提醒未保存数据风险，Windows 不增加确认窗口。

3.4.2：本地升级先校验包、关闭连接并释放共享输入，等待旧接收端退出后才解压替换，通过 start.bat --upgrade 启动，CMD 自动退出且不增加窗口。暂存、备份和启动日志改在安装目录 .upgrade 中，避免与 APPDATA 跨盘导致替换失败。安卓自动等待原电脑重新连接并核对本次任务结果。
旧版正在运行的更新代码无法被 ZIP 内的新模块提前替换；若 3.4.1 跨盘更新失败，请手动完整覆盖 3.4.2 并重新启动一次，后续使用新流程。

3.4.3：修复便携 Python 找不到 storage_reads 模块导致启动退出码 1。若 3.4.2 接收端已无法运行，请解压完整 3.4.3 Windows ZIP，退出旧进程后覆盖原目录，再运行 Start.exe；原有 APPDATA 配置保留，无须卸载。发布前会使用实际 ZIP 内 Python 验证 GUI 和升级批处理启动。

3.7.0 网络与蓝牙：安卓「系统与应用」或「启动与网络」进入新管理页。
热点：启停、重启、修改 SSID／密码／频段、查看客户端地址与主机名。密码留空沿用旧值，不显示旧密码；不支持单独踢出客户端，可换密码并重启。
Wi-Fi：扫描（数秒后刷新）、查看信号、保存或更新当前用户连接密码、连接／断开／忘记。企业网络先在 Windows 配置后使用已保存配置；密码不是路由器管理密码。新 Windows 的附近网络权限由系统管理。
蓝牙：开关、搜索可发现设备、查看配对／连接状态、配对／取消配对。在手机核对验证码或输入 PIN；未确认超时取消。音频、鼠标等连接由对应 Windows 设备服务建立，并非所有设备支持通用强制连接。
网卡：查看 IP、网关、DNS、MAC 和链路信息；启停、修改／恢复自动 DNS、DHCP 续租。更改需要电脑既有权限，不自动弹出提权。
网络操作后台执行，不阻塞接收连接。连接中断后重新连原电脑查询任务，不重复提交；手机离开配对页可能导致验证超时。密码／PIN 不保存到任务与界面恢复数据。Windows 不新增应用弹窗，系统必需的权限、安全验证仍由系统管理。

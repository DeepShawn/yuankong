LanCmd Windows 接收端 v1.2
========================================

这个文件夹已经是编译好的成品，不需要安装 Python，
解压后直接双击 LanCmdAgent.exe 就能用。


一、第一次使用
----------------------------------------
1. 双击 LanCmdAgent.exe
   -> 不会有任何窗口弹出，它已经在后台运行了。
   -> 打开任务管理器能看到一个 LanCmdAgent.exe 进程。

2. 手机打开 LanCmd App，会自动找到这台电脑。
   第一次连接时，本机会弹一个确认框：
   "设备 xxx 请求控制本机" -- 点【是】。
   之后这台手机就永久免确认了。

3. 想开机自动运行：
   双击 LanCmdCtl.exe 是没用的，要在命令行里执行：
   LanCmdCtl.exe --install-autostart

   或者按住 Shift 右键这个文件夹 -> 在此处打开命令窗口，
   然后输入上面那行命令。


二、两个 exe 分别干什么
----------------------------------------
LanCmdAgent.exe   主程序。双击就后台运行，没有窗口。
                  这个是你平时要用的。

LanCmdCtl.exe     管理工具。有命令行窗口，用来查看状态、停止、装自启。
                  因为主程序没有控制台，它自己带参数看不到输出，
                  所以查状态一律用这个。

  LanCmdCtl.exe --status               查看是否在运行、端口、已配对设备
  LanCmdCtl.exe --stop                 停止接收端
  LanCmdCtl.exe --auto-accept          允许局域网任意设备直接连（不弹确认框）
  LanCmdCtl.exe --no-auto-accept       恢复成需要确认
  LanCmdCtl.exe --install-autostart    开机自启
  LanCmdCtl.exe --uninstall-autostart  取消开机自启
  LanCmdCtl.exe --reset-pairing        清除所有已配对设备


三、文件说明
----------------------------------------
LanCmdAgent.exe        主程序（无窗口）
LanCmdCtl.exe          管理工具（有窗口）
lan_command_agent.py   主逻辑源码，程序运行需要它，不要删
python\                自带的 Python 运行时，不要删
使用说明.txt            本文件

配置文件、日志、配对记录都在：
  %APPDATA%\LanCmd\agent.json     配置
  %APPDATA%\LanCmd\agent.log      日志
  %APPDATA%\LanCmd\paired.json    已配对设备


四、注意
----------------------------------------
1. 整个文件夹要一起保留，不要只把 exe 拷走。
   exe 需要同目录的 python 文件夹和 .py 文件才能运行。

2. 装完自启后不要再移动文件夹位置。
   注册表里记的是绝对路径，移动后自启会失效。
   要移动的话，移动完重新执行一次 --install-autostart。

3. 第一次连接时的确认框是系统原生弹框
   （打包版没带 tkinter，用的是 Windows 自带对话框），
   样子朴素但功能一样，点【是】就好。

4. Windows 防火墙第一次可能弹提示，要允许 Python 访问网络，
   否则手机连不上。

5. 杀毒软件如果报毒：这是自己编译的程序，误报。
   加信任即可。


五、连不上的排查顺序
----------------------------------------
1. 双击 LanCmdCtl.exe --status 看是不是"运行中"
2. 手机和电脑是不是连的同一个 Wi-Fi
3. Windows 防火墙有没有放行
4. 路由器是不是开了"AP 隔离"（开了设备之间不能互访）
5. 都不行就在 App 里用"手动输入 IP"填电脑的局域网 IP

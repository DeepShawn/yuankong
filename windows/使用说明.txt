LanCmd Windows 接收端 v1.4.4
========================================

这个文件夹已经是编译好的成品，不需要安装 Python。
双击 Start.exe 就能用。


一、最简单的用法
----------------------------------------
双击  Start.exe

  -> 弹出一个小面板，显示「接收端运行中」还是「未运行」
  -> 点「启动接收端」，状态变成绿色运行中
  -> 面板上会显示本机地址，手机 App 可以用它手动连接
  -> 关掉面板不影响接收端，它在后台继续跑

不想开面板，也可以直接双击  start.bat
（会弹个命令行窗口，显示启动结果后等你按键关闭）


二、三种启动方式随便挑一个
----------------------------------------
Start.exe        双击，有窗口有按钮，最直观            ← 推荐
start.bat        双击，命令行确认一下，然后自动关闭
LanCmdAgent.exe  双击，完全没有提示，静默运行


三、手机连电脑热点（重点）
----------------------------------------
这个场景有两条坎，都已经处理好了，但还是说清楚免得踩坑：

【坎一】防火墙没放行
  电脑开热点后，手机连的那个网络被 Windows 判为「公用网络」，
  47823 / 47824 端口默认被防火墙拦掉。表现是手机完全搜不到，或者连一下就断。

  修复办法（二选一）：
    a) 双击 Start.exe，点「修复防火墙」，会请求管理员权限，点「是」
    b) 或者右键以管理员身份运行 LanCmdCtl.exe，执行
         LanCmdCtl.exe --fix-firewall

  Start.exe 上如果显示「防火墙未放行 !」，就是这个问题。

【坎二】热点下 UDP 广播会被系统丢掉
  接收端已经处理了：手机会主动向「网关」单播探测。
  连电脑热点时，网关就是这台电脑（一般是 192.168.137.1），
  所以即使广播失效，也能通过单播找到电脑。

  手动兜底：App 里「手动输入 IP」填 192.168.137.1

【注意】手机连电脑热点时是没有互联网的，这是正常的。
  但有些手机会因为「此网络无法访问互联网」自动切回移动数据，
  那样就断开了。需要在手机的 Wi-Fi 设置里
  把这台热点设为「保持连接」或关掉「自动切换到移动数据」。


三、手机怎么连
----------------------------------------
1. 手机连同一个网络：
     - 和电脑连同一个 Wi-Fi
     - 或者连电脑开的热点（Windows 设置 → 网络和 Internet → 移动热点）
   两种情况都支持。电脑开热点时，手机直接把网关当电脑连，不依赖广播。

2. 打开 LanCmd App，会自动发现这台电脑。

3. 首次连接时，电脑会弹一次确认框「设备 xxx 请求控制本机」，点【是】。
   之后这台手机永久免确认。

4. 如果扫不到，用 App 里的「手动输入 IP」填面板上显示的本机地址。


四、VPN 开着也能用
----------------------------------------
手机开 VPN 时，系统会把广播从 VPN 网卡发出去，导致扫不到电脑。
这个版本已经处理：

  - 广播改成绑定到 Wi-Fi/网卡逐个发，绕开 VPN 隧道
  - 电脑端会告诉手机自己所有网卡地址，手机挑同网段的连
  - 万一广播被拦，直接连网关（开热点时网关就是电脑）

电脑端也一样：接收端会跳过 VPN 网卡，不会把地址报错。

如果还是连不上，把 VPN 关掉试一次，能连通就说明是 VPN 的路由策略
把局域网流量也劫持了，需要在 VPN 客户端里把局域网加入直连白名单。


五、管理命令
----------------------------------------
Start.exe 面板上能做的：启动 / 停止 / 开机自启 / 打开配置目录

命令行方式（双击 LanCmdCtl.exe 后输入，或 Shift+右键在此处打开命令窗口）：

  LanCmdCtl.exe --status               查看是否在运行、端口、已配对设备
  LanCmdCtl.exe --stop                 停止接收端
  LanCmdCtl.exe --auto-accept          允许局域网任意设备直接连（不弹确认框）
  LanCmdCtl.exe --no-auto-accept       恢复成需要确认
  LanCmdCtl.exe --install-autostart    开机自启
  LanCmdCtl.exe --uninstall-autostart  取消开机自启
  LanCmdCtl.exe --reset-pairing        清除所有已配对设备


六、文件说明
----------------------------------------
Start.exe              启动面板，双击这个最省事
start.bat              命令行启动，双击也可以
LanCmdAgent.exe        接收端本体（无窗口）
LanCmdCtl.exe          命令行管理工具
lan_command_agent.py   主逻辑源码，程序运行需要它，不要删
python\                自带的 Python 运行时，不要删
使用说明.txt            本文件

配置、日志、配对记录在：
  %APPDATA%\LanCmd\agent.json     配置
  %APPDATA%\LanCmd\agent.log      日志
  %APPDATA%\LanCmd\paired.json    已配对设备


七、注意
----------------------------------------
1. 整个文件夹要一起保留，不要只把 exe 拷走。
   exe 需要同目录的 python 文件夹和 .py 文件。

2. 装完自启后不要再移动文件夹位置。
   移动了就在 Start.exe 里重新点一次「开机自启」。

3. 首次连接时那个确认框是系统原生对话框（打包版没带 tkinter），
   样子朴素但功能一样，点【是】就好。

4. Windows 防火墙第一次可能提示放行，务必允许，
   否则手机连不上。

5. 连不上的排查顺序：
     Start.exe 看是不是「运行中」
     -> 手机和电脑是不是同一个网络
     -> 防火墙有没有放行
     -> 路由器/热点有没有开「AP 隔离」
     -> 关掉 VPN 再试
     -> 连热点的话：Start.exe 点「修复防火墙」
     -> 用「手动输入 IP」填面板上的地址
        （连热点时填 192.168.137.1）
